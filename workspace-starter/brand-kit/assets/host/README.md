# 主持人（占位）

每期开工时技能会问“这期谁当主持人”：真人口播、固定插画角色、头像角标，或者用故事主角代替。固定下来的东西放在这里。

- 真人或头像角标：放一张正方形头像，比如 `avatar.png`，`host-badge` 组件的 `avatar` 变量指向它。
- 固定插画角色：每个角色一个文件夹 `<角色名>/`，里面放 `character.json`（长相、标志物、身材比例、配色、线条画风）、`sheet.png`（确认过的设定图）和表情动作组（透明底 PNG）。
- `HOST_PROMPTS.md`：做设定图、表情组、线稿观众和场景用的提示词模板。技能第一次用插画角色时会读它。

怎么做见 [工作区初始化指引](../../../../WORKSPACE_SETUP.md) 第 6 步。
