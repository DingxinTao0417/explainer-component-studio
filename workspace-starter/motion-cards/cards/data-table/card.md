## 命门

1. **先有表头，再一行一行进数据。** 表头 0.8 秒前落定，第一行 0.95 秒才升起，行与行默认隔 0.32 秒。所有行一起出来，观众一眼看到十几个数字，不知道旁白正在说哪一行；行间隔忽长忽短又会读成“这几行有轻重”。要跟旁白就用 `cues` 写每行的秒数，不要改成一起进；`cues` 写得太挤时脚本也会把相邻两行拉开到至少 0.12 秒。
2. **高亮带扫到哪格，哪格才变色、顿一下。** 每格变色的时刻是 `hit + 0.45 × (1 − ∛(1 − f))`，f 是这格**文字**的中心在高亮带里的位置（高亮带用 power2.out，这样算出来正好是带子前沿经过文字中心的那一帧）。默认第 3 行的四格依次在 2.62、2.69、2.75、2.85 秒变色。不能按格子中心算：名称列很宽、字靠左，横屏格子中心在字右边 73px，带子已经盖过“分步引导”四个字，字还是黑的。整行同时变色，读起来是“这一行本来就是橙色的”，扫的动作就白做了。
3. **数字滚完、站稳了才高亮。** hit 至少等最后一行开始后 0.85 秒（0.8 秒滚动加 0.05 秒），早了脚本自动往后推。数字还在跳就被高亮，观众会以为高亮的是一个中间值。滚动时每个数字框按最终值宽度加 4px 锁死、右对齐，最右一位和单位不动；不锁的话 0 → 12.4s 这一列会跟着位数左右晃，像表格在抖。

## 动作拆解

默认 3 行，横屏实测：表格 1152×472px（画面宽的 60%），整块 236–844px 竖向居中；竖屏表格 842×423px，整块 495–1041px，中线在 768px（40%）。

| 时间 | 谁 | 做什么 | 缓动 |
| --- | --- | --- | --- |
| 0.1 → 0.6s | 标题 | 从下方 36px（竖屏 32px）升到位，淡入 | out |
| 0.3 → 0.6s | 外框 | 淡入（底色加 2px 细边，圆角 22px / 竖屏 18px） | none |
| 0.35 → 0.8s | 表头底条 | 从左端擦出，scaleX 0 → 1 | snappy |
| 0.45s 起，每个隔 0.07s | 表头文字 | 从左边 24px（竖屏 18px）滑到位，淡入，各 0.35s | power3.out |
| 0.95 / 1.27 / 1.59s | 每一行 | 从下方 44px（竖屏 36px）升到位，0.5s；外框内沿以下的部分被裁掉，像从表格里长出来；文字格和分隔线 0.35s 淡入，数字格 0.2s 显出 | power3.out / power1.out / none |
| 每行开始起 0.8s | 数字格 | 从 0 滚到目标值，保留小数位、千分位、正负号、前缀（¥、约）和单位（%、s、万） | power3.out |
| 2.6 → 3.05s | 高亮带 | 行：宽度从 0 长到整行，从左往右；列：高度从 0 长到整列，从上往下。补的是宽高不是缩放，3px 描边和 14px 圆角一直不变形。浅底是 10% 强调色 | power2.out |
| 2.62 / 2.69 / 2.75 / 2.85s | 被扫到的格 | 0.12s 变成强调色；数字格同时放大到 1.14 倍（0.12s）再回到 1（0.3s） | none / power2.out / back.out(3) |
| 2.98 → 3.34s | 角标 | 缩放 0 → 1 | back.out(2.4) |

最后一行的数字 2.39 秒滚完，时间轴 3.34 秒结束，之后静止到 4 秒。

## 参数手感

| 参数 | 默认 | 调大 | 调小 |
| --- | --- | --- | --- |
| CFG.each 行间隔（`cues` 留空时） | 0.32s | 过 0.6s 变成一行一行地念，适合旁白真的逐行停顿 | 低于 0.2s 几行像一起进来，见命门 1 |
| CFG.minGap 行最小间隔 | 0.12s | 只在 `cues` 写得太挤时起作用；过 0.3s 会把对好旁白的行往后推 | 0 时几行能挤在同一刻进，见命门 1 |
| CFG.roll 数字滚动 | 0.8s | 过 1.2s 最后一行要等很久，hit 跟着被推迟 | 低于 0.4s 看不出滚，只像闪了一下 |
| CFG.sweep 高亮带扫过 | 0.45s | 过 0.8s 拖沓，旁白已经说到下一句 | 低于 0.25s 像整行一下子变色，见命门 2 |
| CFG.pop 数字顿一下 | 1.14 倍 | 过 1.25 倍，竖屏 48px 的 5 位数字每边多出约 15px，格边距只有 20px，会碰到邻格 | 低于 1.06 倍看不出顿 |
| LAND.slide / PORT.slide 行升起 | 44 / 36px | 过 80px 时最后一行起步时大半截在外框下沿以下、被裁掉（横屏行高 125px），像空了一下才冒出来 | 低于 20px 只剩淡入，没有“站定” |
| LAND.fb / PORT.fb 正文起始字号 | 56 / 48px | 放大后更早触发缩字、堆叠和换行 | 挤不下时脚本自己缩，最小 40px（fmin） |
| LAND.t1 / t2 / tmin 横屏标题 | 64 / 68 / 60px | t1 调大，一行里缩得少、更早折成两行（调到 72px 时 17 字就折行） | tmin 低于 60px，长标题会和 56px 的正文一样大，层级倒过来 |

## 已知坑

- **哪些格会滚动。** 一格是“最多 3 个符号的前缀 + 数字 + 最多 4 个字的单位”就当数字滚（实测 ¥0.08、12.4s、-7.7%、+20%、12,800、约 12 万、¥198/年、12 Mbps 都对）；1:32、v2.1、GPT-4o、1920×1080 自动当文字，名次（第1名）也当文字，不会从“第0名”数上去；单位超过 4 个字的（120 tok/s）当文字，不滚、不加粗。年份、编号这类像数字又不该滚的，开头加英文单引号：`'2024`，画面上不显示这个引号。写在挂载片段的 `data-variable-values` 里时，属性本身是单引号包着的，这个引号要写成 JSON 转义 `\u0027`（如 `"rows":"版本|\u00272024"`，HyperFrames 0.8.174 实测显示为不滚动的 2024）或 HTML 实体 `&#39;`；直接写 `'` 会把属性提前截断，整串变量都读不出来。
- **时间会被推迟。** 实测 4 行、`cues` 写 1.0,1.8,2.2,3.0、`hit` 写 3.2，高亮带 3.85 秒才开始扫：对旁白时先排 `cues`，再让 `hit` 不早于最后一个 cue 加 0.85 秒。早于 0.65 秒（表头还没落定）的 cue 推到 0.65 秒，相邻两行至少隔 0.12 秒：实测写 0.2,0.3,0.4、`hit` 写 0.5，三行在 0.65、0.77、0.89 秒进，高亮推到 1.74 秒。6 行用默认间隔时最后一行 2.55 秒进，高亮推到 3.4 秒，全部落定 4.14 秒，片段时长要写 4.5 秒以上。
- **标题多长。** 标题始终比正文大（横屏正文 56px，竖屏 48px）。横屏 76px 一行，放不下先在一行里缩到 64px，再放不下折成两行（两行字数接近），68px 起、最小 60px，还放不下就是三行。默认宽度（表格 1152px）实测：15 字以内 76px，16 字 72px，18 字 64px，19–32 字两行 68px，38 字两行 60px，39 字起三行 60px；5 列的宽表格（最宽 1440px）能多放几个字。竖屏标题固定 72px（规格里竖屏标题的下限），不缩只折行：11 字一行，12–22 字两行，23–33 字三行，34 字起四行，每多一行表格少 86px 高度。
- **挤不下时的退路。** 宽度不够，按这个顺序：正文缩到 40px → 表头缩到 34px（竖屏 32px）→ 竖屏改成堆叠（每行的第一格提到这一行上方单独一行，表头去掉第一列的名字）→ 超过 6 个字宽的文字格换行（靠左，两行字数接近）→ 所有文字格换行；表头和数字格永远不换行。高度不够：行距（横屏到 12px，竖屏到 8px）→ 正文 40px → 横屏标题到 60px → 表头 34 / 32px → 整块等比缩小，保证不出竖屏安全区，但这时正文小于 40px。竖屏实测：4 列 × 6 行短格配两行标题和列角标，不缩，占 249–1287px；5 列 × 6 行配一行标题和列角标，不缩，正文 42px；同样内容配两行标题，缩到 0.98 倍；4 列 × 6 行、“做法”列每格 16 字（堆叠后折成两行），缩到 0.86 倍，正文约 34px，同样的内容 4 行或 5 行不缩。竖屏要放 6 行又有要折行的文字格时，把文字写短或拆成两张表。竖屏 5 列一律堆叠；4 列时名字太长也会堆叠。`verify` 只测默认变量，换了内容要自己用 `?o=portrait&guides=1` 看一眼。
- **`backdrop` 填 `off` 时标题没有底。** 表格自带底色和边框，但标题直接压在下面的画面上：实测深色皮的浅色标题压在中灰条纹上，`check` 报 2.6:1。压在亮或花的画面上时把 `title` 留空，标题交给别的卡。

## 动效与皮的边界

属于这张卡的：外框和表头先于数据出现；表头从左擦出；行按 cue 从下方升起并站定；数字从 0 滚动、单位和最右一位不动；高亮带沿行从左到右、沿列从上到下长出来；格子在带子前沿经过文字时才变色并顿一下；角标最后弹出。

只是皮、可以随便换的：强调色（`--mc-accent`）、字体和字号、圆角、表头底色（`--mc-panel`）、分隔线换成斑马纹、高亮带是描边加浅底还是实底（换实底时被扫到的字要改成 `--k-on-accent`）、角标的形状、有没有标题。

## 接进片子

- 变量：`title` 标题，可留空，空时只有表格；`cols` 表头，用 `|` 分隔，2–5 列，第一列放名称（左对齐、加粗）；`rows` 内容，行用 `;`、格用 `|`，2–6 行，格子少了补空、多了截掉；`mark` 填 `row:3`（第 3 行，不算表头）、`col:2`（第 2 列，算第一列）或 `none`；`badge` 角标，只在有高亮时出现，行高亮贴在这一行名字后面，列高亮立在这一列表头上方；`hit` 高亮带开始扫的秒数；`cues` 每行出现的秒数，逗号分隔，写得比行数少时按最后两个数的间隔往后排，留空是 0.95 秒起每 0.32 秒一行；`backdrop` 填 `off` 时去掉整屏底色，只留表格。
- 竖屏堆叠时高亮列：高亮带是一整条竖带，从各行名字那一行后面穿过，名字压在 10% 的浅底上仍然清楚；高亮第 1 列时没有竖带（名字行横跨整张表），名字从上到下依次变色，角标放在表格左上方。
- 起始时间：让第一行（卡内 0.95 秒，或 `cues` 的第一个数）对上旁白念到第一个对象的那个词；`hit` 对上“最快的是……”“看这一列”里的关键词。
- 音效：每行进来一个轻 tick（默认 0.95、1.27、1.59 秒），高亮带一个 whoosh（2.6 秒），角标一个 pop（2.98 秒）。
- 横竖两用：片段写 `data-width="1920" data-height="1080"` 是横版，写 `1080` × `1920` 是竖版，变量和节奏不变；竖屏超过 4 列自动堆叠（见“已知坑”）。
- 常和 `bar-grow`、`stat-compare` 连用：这张卡先把全貌摆出来，再用 `bar-grow` 把高亮的那一列画成柱子，或用 `stat-compare` 只拿出两个数正面对比。
