整张卡是一个生成出来的无字界面（侧栏、顶栏、六块卡片，卡片里是柱和折线，颜色跟着换皮走），镜头对着其中一块被选中的卡片，分三挡放大：全景 1 倍，第 1.17 秒硬切到 1.6 倍，第 2.33 秒再硬切到 2.6 倍（竖屏 2.4 倍）。切换那一帧没有任何补间，放大中心钉在目标卡上，所以目标卡在屏幕上不动，周围的东西向外涌。

## 命门

1. **三挡必须钉在同一个点上，而且是真的硬切。** 放大中心是目标卡上的一个固定点，三挡共用。每挡重新构图、或者给放大加一小段补间，读成三个不同的镜头或者一次平滑推近，都不再是跳切。代码里放大倍数只在 1.167 和 2.333 两个时刻各变一次。
2. **挡差不能小于 1.5 倍，每挡至少停 1.1 秒。** 横屏 1 → 1.6 → 2.6，前一挡到后一挡是 1.6 倍和 1.63 倍；挡差再小，观众读成画面抖了一下，而不是“更近了”。每挡的停留 1.167 秒，足够认出这一挡的构图，再被下一刀打断。
3. **每一跳压两帧暗脉冲，当作听得见的节拍点。** 切换帧起 2 帧（0.067 秒）整画面亮度降到 0.92。没有这两帧，硬切读成丢了几帧；脉冲压得太深或太久，读成闪黑。最后一挡 0.533 秒收完 0.8% 的推近后必须真静止，打断类的动作要靠末挡的静止把“就是它”交代清楚。

## 动作拆解

| 时间 | 谁 | 做什么 | 缓动 |
| --- | --- | --- | --- |
| 0 → 1.167s | 整个画面 | 全景 1 倍，沿放大中心极慢推近 0.8%（1 → 1.008） | smooth |
| 1.167s | 放大倍数 | 无补间切到 1.6 倍；1.167 → 1.233s 亮度 0.92 | 硬切 |
| 1.167 → 2.333s | 整个画面 | 在 1.6 倍上再推 0.8% | smooth |
| 2.333s | 放大倍数 | 无补间切到 2.6 倍（竖屏 2.4 倍）；2.333 → 2.4s 亮度 0.92 | 硬切 |
| 2.333 → 2.867s | 整个画面 | 在末挡推 0.8%，之后一帧都不再动 | out |
| 2.333 → 2.6s | 目标卡的选中环 | 边线不透明度 42% → 85%，外晕 7% → 14%，“就是它”加深一档 | out |
| 每一挡 | 暗角 | 强度 0.10 → 0.14 → 0.18，视线收向目标卡；深色皮 0.45 → 0.5 → 0.55 | 随挡位 |
| 0 → 2.867s | 颗粒 | 每 2 帧换一张，不透明度 4.5%；2.867 秒起冻结，末挡尾段是真静止 | — |

末挡 2.867 秒落定，到 4.5 秒结束共停 1.633 秒。

## 已知坑

- 竖屏的格子是细高的：把界面按 1080×1920 生成，每块卡约 294×911，所以目标换成第一行中间那张，钉点放在卡的 78% 高处，让放大后的卡片压住上边、下缘（含选中环）停在 y 1266，在 1306 的字幕线以内。换成别的目标卡要重看钉点，第二行的卡在竖屏里会掉进字幕区。
- 末挡横屏时目标卡比画面还高（卡高 452 像素，放大 2.6 倍是 1176 像素，画面高 1080）：选中环上缘在 y 210，下缘出画，左右在 x 374–1774；这是原版的构图，不是 bug。竖屏末挡选中环在 x 240–966，在左右 10% 的线以内，上缘出画。
- 放大用的是 CSS `zoom`，浏览器按放大后的尺寸重新栅格化，2.6 倍下线条还是锐的；不要改成 `transform: scale`，那样会糊。`zoom` 会把节点自己的 `left / top` 一起放大，所以位置写成“钉点除以倍数再减钉点”，钉点才不会漂。
- 界面是脚本生成的，不跑脚本时只有一个底色和一层暗角，静态页不是最终画面。（数据生成的图形，规格允许。）
- `backdrop: off` 时去掉底色、暗角和颗粒，界面的侧栏、顶栏、卡片仍是实色，只有它们之间的空隙透出宿主画面；它压在别的画面上更像“一块界面窗口在推近”，不是透明叠层。包裹层上的 `data-layout-allow-overflow` 是有意的：放大后的界面按设计比画面大。

## 动效与皮的边界

属于这张卡的：三挡放大钉在同一点上、切换帧零补间、每一跳两帧暗脉冲、挡差不小于 1.5 倍、末挡真静止、选中环在第三跳加深一档、暗角随挡位收紧。

只是皮的：界面里卡片的数量、柱和折线的样子、颜色（`--k-*`）、选中环的颜色、颗粒强弱、目标卡是哪一张。要换成真实界面截图时，把画面换成 `ui.png` 之类的整张图，放大中心换成图上的目标位置，三挡的时间不动。（示例图是 1 倍，放大到 1.6 倍以上就糊，所以这张卡默认用生成的界面。）

## 接进片子

- **变量**：只有 `backdrop`。卡里没有可填的文字，界面是无字的示意；要在目标卡上放真实读数，用字幕或标注卡叠在上面，叠的位置按末挡的目标卡（横屏约 x 374–1774，竖屏约 x 240–966、y 230–1266）。
- **起点**：第 1 个切点（1.167 秒）对旁白里的“看这里”，第 2 个切点（2.333 秒）对“就是它”；每一跳放一个 `tick`，第三跳可以换成更重的一声。整张卡算一次整屏的打断，同一片里整屏冲击最多 3 次、间隔至少 16 拍。
- **横屏、竖屏**：同一条时间轴，只换版式。竖屏三挡是 1、1.6、2.4，目标是第一行中间那张。目标卡是生成界面里固定的那一张，无法用 x / y 指向别处。
- **渲染**：卡里动了 `filter`（亮度脉冲），MT 卡的快速截帧可能和 GSAP 卡有抗锯齿级的差别，成片用 `render -w 4`。
- **搭配**：先用 `crash-zoom` 或 `push-through` 这类连续推近交代主体，再用这张卡把注意力钉到一点上；之后接 `freeze-annotate` 标注。同一镜头不要再叠变速、定格这类动作（同一镜头只放一个“时间操纵者”），节拍会打架。
