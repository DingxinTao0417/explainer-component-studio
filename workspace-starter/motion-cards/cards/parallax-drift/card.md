## 命门

1. **同向，速度差至少两倍一级。** 三层的位移比是 0.14 : 0.45 : 1，相邻两层差两到三倍。差距小于 1.5 倍，看起来是整个画面在平移；有一层反着走，读成的是物体各自在动，不是镜头在动。
2. **线性，贯穿整镜。** 和慢推一样，从第一帧走到最后一帧，不加缓动。任何一处减速都会让观众看出“这一层停了”，空间感立刻塌掉。
3. **近层要虚、要暗。** 近层模糊 9px、亮度压到 42%，远层模糊 5px、亮度 50%，只有中层是清楚的。三层一样清楚时，眼睛分不出谁近谁远，速度差只会显得乱。

## 动作拆解

| 时间 | 谁 | 做什么 | 缓动 |
| --- | --- | --- | --- |
| 0 → 5s（= `dur`） | 远层（铺满的底图） | 横移 +21px → −21px，共 42px | none |
| 0 → 5s | 中层（两张图卡） | 横移 +67.5px → −67.5px，共 135px | none |
| 0 → 5s | 近层（前景剪影） | 横移 +150px → −150px，共 300px | none |

每一层都以自己的静态位置为中点，前半镜在它右边，后半镜在它左边；2.5 秒那一帧就是不跑脚本时看到的版式。

## 参数手感

| 参数 | 默认 | 调大 | 调小 |
| --- | --- | --- | --- |
| dist 近层总位移（变量） | −300px | 绝对值过 500 近层像有人走过去，抢戏 | 低于 150 中层只走 60 多像素，视差看不出来 |
| dur 时长（变量） | 5s | 时长翻倍时 `dist` 也跟着加一半左右，保持每秒 40–60px 的近层速度 | 短于 3 秒按比例减小 `dist` |
| midRate 中层速度比 | 0.45 | 靠近 1 时中层和近层粘成一层 | 低于 0.3 时和远层粘成一层 |
| farRate 远层速度比 | 0.14 | 过 0.25 需要更大的底图余量 | 0 时远层是贴死的背景，也成立，只是少一层深度 |
| 近层模糊 / 亮度 | 9px / 42% | 更虚更暗时近层退成一块影子，更安全 | 清楚明亮的近层会挡住中层还抢视线 |

## 已知坑

- 近层越漂越挡住中层：默认向左漂，到 4.8 秒时前景剪影已经盖住第二张图卡的右下角。这是视差自带的效果（遮挡变化是最强的深度线索），但被盖的不能是要读的内容。排版时用近层的**终点位置**检查，不是静态位置。
- 远层的余量：底图每边只比画面多 120px，再减去 5px 模糊吃掉的边，实际可用约 100px。远层位移是 `dist × 0.14 ÷ 2`，脚本把 `dist` 限制在 ±700 以内就是为了这个；自己把 `farRate` 调大时要同步加宽底图。
- 底图太抢眼：示例图都是高饱和的色块，远层原样铺上去会和中层的图卡搅在一起，所以远层压到了 50% 亮度、85% 饱和度并加模糊。换成本来就暗的底图时把亮度往回调。
- 连拍图里远层几乎不动（每格只走几个像素），判断时看中层图卡的左边距和近层的位置变化。
- 中层的两张图卡是同一层、同速的。想让它们也分前后，要把其中一张挪到新的一层并给它 0.6 左右的速度比，不要在同一层里给两个速度。

## 动效与皮的边界

属于这张卡的：三层、同向、线性、两倍以上的速度级差、近虚远暗中间清楚。

只是皮：每层放什么（照片、图卡、图标、文字块都行）、图卡的白边和圆角、近层用人物剪影还是别的物体、往左还是往右漂。

## 接进片子

- 变量：`src` 远层底图，`mid` / `mid2` 中层两张图，`near` 近层的透明底前景图，`dist` 近层总位移（负数向左，正数向右），`dur` 这一镜的秒数，`backdrop`。
- 起点就是这一镜的起点，`dur` 填这一镜的真实时长；不需要对旁白的词。
- 音效：不配。
- 连用：中层的图卡可以先用 media-pop 的方式落进来，落定后整镜开始漂；上面照常叠字幕和名条（字幕不要放进任何一层，它应该是不动的）。
