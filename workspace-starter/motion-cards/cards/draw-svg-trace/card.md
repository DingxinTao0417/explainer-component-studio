## 命门

1. **笔头要看得见，线要先于内容。** 墨线一圈跑 1.33 秒（0.33 → 1.67s），跑的时候卡片里是空的，笔头在最前面：三段越来越粗的短线（粗 6.4 / 8 / 9.6px，长度占整圈 4% / 2.4% / 1.1%）加一颗半径 7.5px 的圆笔尖。没有笔头，读成“边框在变长”；内容抢在线闭合之前出来，“画出来”的因果就断了，所以第一块内容要等 1.73 秒（闭合后 0.07 秒）才开始上墨。
2. **闭合要有一个句号。** 1.67 秒线刚好合上，立刻在 0.07 秒里从 6px 加粗到 11px 并冲成纯黑（深色皮下冲纯白），再用 0.2 秒回落。这一下去掉，线合上就只是停住，观众看不出“画完了”。白底上用加深加粗，不用发光。
3. **描边的圆角必须等于卡片圆角。** 描边矩形的 rx 是 28px，和卡片面、发丝边的圆角一样，线在 1.87 → 2.2 秒淡出、卡片自己的发丝边同时淡入，两者要完全重合。圆角差几个像素，交棒的那一瞬间轮廓会跳形。脚本按量到的卡片尺寸画线，圆角常数只有 `CFG.rx` 和 CSS 里三处 28px，改要一起改。

## 已知坑

- 卡片尺寸只写在 CSS 里（横屏 1120×660，竖屏 768×960），脚本量出来画线。想换尺寸只改 CSS 的 `.dt-card`。卡片内容是定高的，字太多会往下挤：竖屏标题折成两行（`mixed` 一组实测）还放得下，署名行上方约留 40px；标题、说明、署名小字都折行（`long` 一组）时，柱图叠到了署名行上。
- 长度上限，横屏：标题 7 个汉字以内保持 72px，到 13 个汉字缩到 40px 仍是一行，再长折行；说明一行 13 个汉字（40px 不再缩），再长折成两行并贴近署名线；大数字 188px，`42%` 宽 371px，`12,480` 宽约 523px（栏宽 560px），再长会缩小。竖屏：标题 72px 不再缩，一行约 8 个汉字，超过折行；说明一行约 16 个汉字；大数字 168px，`12,480` 约 467px（栏宽 672px）。眉题缩到 28px 仍放不下才折行；竖屏折行会把下面整块往下推。
- 眉题、说明、署名、小字都能留空，留空时整块隐藏；署名留空时署名旁的小字也留着，两个都空整行消失。标题留空后大数字顶上来，柱图小标题仍在右栏。
- 描边矩形用 `pathLength=1` 免测周长；空隙写成 2、起始偏移落在空隙里，所以动作开始前起笔点不会留一个小点。笔头三段短线的空隙也是 2，不会在起笔时绕回路径末端冒出一截。 点阵、暗角和颗粒只在 `backdrop: on` 时有；`off` 只留卡片、描边、标记。
- 描边层和裁切标记都盖在卡片内容上面，但内容在线闭合后才出现，描边在 1.87 秒后淡出，检查不会报遮挡。它们压在 `backdrop: off` 的宿主画面上时，黑线在深色画面上看不见：深色宿主改用深色皮（`--mc-ink` 换亮色）。

## 动效与皮的边界

属于这张卡的：先预告（四角标记）再描边、笔头跑在线的最前面、闭合那一下加深加粗、描边交棒给卡片自己的发丝边、内容在闭合之后才逐块上墨、柱子在内容之后从基线长出。

只是皮、可以随便换的：卡片里放什么（眉题、标题、大数字、柱图、署名）、点阵和暗角、强调色、字体、卡片尺寸和圆角（线圆角要同步改）。

和 `bracket-frame`、`scan-bracket-sweep` 的区别：那两张是一个括号或扫描线去框住已经在画面上的东西；这张是线本身把一个原本不存在的卡片“画”出来，内容在画完以后才有。和 `underline-draw` 的区别：下划线是一笔、单向、给一个词；这里是一整圈闭合轮廓、带交棒。原版末尾还有一笔给大数字的朱红下划线，那是 `underline-draw` 的动法，没有带进来。

## 接进片子

- 变量：`kicker` 眉题、`title` 标题、`value` 大数字、`caption` 说明、`chart` 柱图小标题、`name` 署名、`meta` 署名旁小字，都可留空；`backdrop` 填 `off` 时去掉点阵、暗角和颗粒，卡片和描边压在画面上。切意群用 `|`，打的空格都会保留。
- 起始时间：让卡内 0.33 秒（笔落下）对上旁白点名的那个词；卡内 1.67 秒线合上，是“就是它”的那一拍。
- 音效：笔触声 `draw` 从 0.33 秒起、约 1.3 秒；1.67 秒闭合冲黑那一帧一个 `impact`。这张卡的闭合算一次整屏级的强调，同一个片子里别紧挨着再放同类。
- 横竖两用：片段 1920×1080 是横版，1080×1920 是竖版，变量和节奏不变；竖屏卡片是 768×960 的单列版式，中线在 40%（y 768），文字都在 y 330–1248、x 156–924。裁切标记弹出时最远到 x 108 和 y 240 / 1296，只有线条，没有字。
- 同一片里只画一个主体：同屏两个卡片排队各画一圈会读成加载动画。与整页蓝图描线（`wireframe-draw-on`）二选一，都用会读成重复报幕。
- 渲染：卡里有 `filter: blur` 的上墨，成片用 `render -w 4`（见 SPEC「六」）。
