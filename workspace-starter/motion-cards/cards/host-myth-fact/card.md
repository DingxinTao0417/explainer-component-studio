## 命门

1. **错的先说完整、用正文色。** 误解先以正常的样子站住，观众得先“信”它一下，划掉才有反转。一出来就是灰的、或者一出来就带着删除线，读成“这是个反例”，没有纠正的那一下。
2. **先划，再变灰，再出对的。** 划线 0.3 秒画完，误解才退成灰色；对的说法至少再晚半秒才升起。三件事挤在同一刻，观众来不及看清被划掉的是什么。
3. **错的和对的上下对齐、一样大。** 两句同一个字号、左边对齐，对的在下面。对的写得比错的大，读成“标题和副标题”；左右摆放，眼睛要来回扫，比不出差别。

## 动作拆解

主持人放在一个 1100×900 的框里，贴着画面底边，人脸中线在 x=1460（人在左时 460）；字在另一侧 760px 宽的一栏里，左边距 140（人在左时 1020），顶在 y=300。

| 时间 | 谁 | 做什么 | 缓动 |
| --- | --- | --- | --- |
| 0 起 | 主持人 | 一直在，视频从第 0 秒开始播 | — |
| 0.25 → 0.70s | 引子 | 上移 24px 淡入，52px、次要色 | power3.out |
| 0.55 → 1.00s | 错的说法 | 上移 28px 淡入，最大 84px、正文色 | power3.out |
| 1.30 → 1.60s | 划线 | 从左端外 12px 起笔，略往上爬，划到右端外 12px，中段向上鼓 | power2.out |
| 1.60 → 1.90s | 错的说法 | 从正文色退成次要色 | power1.out |
| 2.10 → 2.55s | 对的说法 | 上移 26px 淡入，和错的同一字号；关键几个字是强调色 | power3.out |

## 参数手感

| 参数（脚本顶部 CFG） | 默认 | 调大 | 调小 |
| --- | --- | --- | --- |
| cut 划线用时 | 0.3s | 过 0.6 像慢慢画了一条线，没有“否掉”的干脆 | 低于 0.15 一闪而过，看不出是划的 |
| over 划线超出两端 | 12px | 过 40 划线伸进别的地方，像画面上的分割线 | 0 时两头刚好卡在字上，像删除线格式 |
| dim 变灰用时 | 0.3s | 过 0.7 变灰拖到对的说法出来，两句抢 | 0 时一下变灰，像换了一张图 |
| gapMin 划完到出对的最少间隔 | 0.5s | 过 1 这一镜变长、口播等字 | 低于 0.3 看不清被划掉的是什么 |
| fsMax 两句的最大字号 | 84px | 过 96 长一点的句子就要缩字号，两句对不齐 | 低于 64 在人旁边显得小 |

## 已知坑

- 两句按较长的那句定字号（按 760px 估算）：9 个字以内是 84px，12 个字 63px。对的说法写长了，错的说法也会跟着变小。
- `reveal` 早于“划完再过 0.5 秒”时，会被推后到那个时刻，旁白就会比字快；把纠正那句话的旁白往后放一点，或者把 `strike` 提前。
- 划线压在字上，所以错的说法上标了 `data-layout-allow-occlusion`。换成别的版式（比如让划线避开字）时，这个豁免要一起去掉。
- 关键几个字（`factKey`）在对的说法里找不到时不标强调色，整句都是正文色。
- 卡里的人物视频每次挂载都从第 0 秒播，而且同一张卡在一个工程里只有第一次挂载的视频有画面（HyperFrames 0.8.174 实测，换文件、改 id 都不行；图片不受影响）。一段口播要连续对口型、或者同一张卡要用两次以上时，把主持人视频放在主时间轴的一层（写法见 README「人物卡」），卡里 `host` 留空、`backdrop` 写 `off`。只用一次时可以直接填 `host`，素材至少和这一镜一样长：`episode.py media <项目> <原片> --start <秒> --duration <秒>` 截一段放进工程。

## 动效与皮的边界

属于这张卡的：人和字各占一边、错的先完整出现、一笔划掉后才变灰、停半拍、对的在下面同样大小地出来。

只是皮：划线的颜色、粗细、弯度，变灰的颜色，对的说法里强调哪几个字，人站哪边，底色，有没有引子。

## 接进片子

- `lead`：引子，“很多人以为”“你可能听说过”，可空。
- `myth`：被纠正的那句说法；`fact`：对的说法；`factKey`：对的说法里最关键的一段，一字不差，可空。
- `strike`：对齐旁白说出“其实”“但”这类转折词的时刻；`reveal`：对齐说出对的说法第一个字的时刻（都用 `align.py find` 查，相对这一镜的起点）。
- `host`：本期主持人的透明底视频或图片，从项目根目录写起；`hostKind` 默认按扩展名自动判断（png、jpg、webp 当图片，其余当视频）；主持人已经在下面一层铺满播放时把 `host` 留空（或者 `hostKind` 写 `none`），`backdrop` 写 `off`，这张卡只留字和划线。
- `side`：人在画面哪边，`left` 时字放到右边。
- 音效：划线一个短 draw，对的说法出来时一个轻 pop。
- 和 `strike-swap` 的区别：那张是在句子里原地换词、压在别的画面上也能用；这张是整屏口播，两句话都留在屏幕上做对比。常接 `host-quote-hold` 把对的说法收成一句结论。
