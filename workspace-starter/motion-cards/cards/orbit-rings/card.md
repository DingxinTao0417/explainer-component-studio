## 命门

1. **匀速，圈和圈不同速。** 五圈 6 秒各转 62°、-44°、32°、-24°、17°，全程线性，相邻两圈反向。同速同向，五个光点会排成一条辐条一起转，变成一根指针。
2. **线细到只是暗示。** 环线 2px，颜色是第二强调色或灰色的四到六成。线一粗，五个同心圆就成了靶子，中间的字像被瞄准。
3. **光点小而少。** 每圈一个，直径 12 到 16px，带一圈很淡的光晕。光点是唯一能看出“在转”的东西，但它一大就成了主角。

## 动作拆解

| 时间 | 谁 | 做什么 | 缓动 |
| --- | --- | --- | --- |
| 0 → 6s | 第 1 圈（直径 480px，实线） | 从 -30° 转到 32° | 线性 |
| 0 → 6s | 第 2 圈（700px，虚线） | 从 200° 转到 156° | 线性 |
| 0 → 6s | 第 3 圈（940px，实线） | 从 115° 转到 147° | 线性 |
| 0 → 6s | 第 4 圈（1200px，实线） | 从 300° 转到 276° | 线性 |
| 0 → 6s | 第 5 圈（1480px，虚线） | 从 48° 转到 65° | 线性 |

光点固定在各自圆环的顶点上，跟着环一起转，自己不做动画。外面两圈比画面高，只露出左右两段弧。

## 参数手感

| 参数 | 默认 | 调大 | 调小 |
| --- | --- | --- | --- |
| speed（变量） | 1 | 过 2 最里圈 6 秒转过三分之一圈，光点明显在跑 | 0.4 以下外圈看不出在转 |
| strength（变量） | 0.7 | 1 时环线清楚，像一张图表的底图 | 0.35 以下只剩光点在飘 |
| turns 的起始角（CFG） | -30 / 200 / 115 / 300 / 48 | — | 几个角度接近时光点会排成一线，见上 |
| turns 的转角（CFG） | 62 → 17，由内到外递减 | 外圈转角比内圈大时，外圈光点的线速度过快 | 都很小时整张卡像静止的图 |

## 已知坑

- 环线和光点都从标题后面穿过。细线没问题；光点转到标题笔画后面时会被字挡住半个，看起来像闪了一下。最里圈在正左、正右各 15° 的范围内会碰到标题，默认的起始角让它只走上半圈；改角度后要重新看五帧。
- 圆环用边框画，转动的是环本身，所以光点不需要单独算位置。不要给环加 CSS 的 `transform` 来居中（会和转动冲突），位置用 left / top 写死。
- 虚线环转动时能看出线段在走，这是有意的；但把五圈全做成虚线，画面会布满爬动的小段，很吵。
- 把圆心移到画面一角时，外圈会变成几条几乎平行的弧线，读成波纹而不是轨道。圆心离开画面中心不要超过 400px。
- 光晕用的是小范围的 `box-shadow`，只有五个，不影响渲染速度；别把它加到环线上。

## 动效与皮的边界

属于这张卡的：同心、细线、不同速、相邻反向的匀速转动，每圈一个随环走的小光点。

只是皮的：圈数（三到六圈）、每圈的直径和线型、线和光点的颜色、圆心位置、光点大小。

## 接进片子

- 变量：`title` 是演示用的标题，接进片子时留空，把标题或关键词卡叠在更高的轨道上并放在圆心；`speed` 是转角倍数；`strength` 是环线和光点的浓度。
- 时间：整镜铺满，不用对齐旁白。
- 音效：没有。
- 常见接法：中心放一个词（`outline-fill-title`），随后的镜头把几个方面逐个摆出来；摆出来的条目可以对齐某一圈环的位置。
