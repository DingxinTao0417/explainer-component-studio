## 命门

1. **光线贴着面板顶边走。** 辉光线的中心钉在面板自己的顶边上（面板坐标 y −2），跟面板一起斜、一起漂；光头的眩光、背后的雾光也跟着同一个 x 走。光线离开边缘浮在空中，就成了一道划过的流星，不再是“光在抚摸界面”（原配方返工过的就是这一条）。
2. **匀速。** 光头在 0.13–4.0 秒从面板左外 260px 线性走到右外 260px，不加缓动。本卡横屏实测“亮度过半的像素”占画面每 0.33 秒是 0 → 2.1% → 8.9% → 12.9% → 17.0% → 19.9% → 21.1% → 22.1% → 21.6% → 18.4% → 13.8% → 5.6% → 0，参考片同一时刻 0 → 1.9% → 8.9% → 12.9% → 16.9% → 19.7% → 20.9% → 21.9% → 21.5% → 18.3% → 13.6% → 5.2% → 0，逐格差不到 0.5 个百分点。光一加缓动就像有人拿着手电在找东西。
3. **有醒有睡。** 面板 0.53 秒内醒来，3.33–4.33 秒沉回黑暗，只留右缘一线蓝色残光。扫完面板还亮着，就成了普通的“扫光高亮”，没有“光走即谢幕”。

## 已知坑

- 面板是 3D 斜放的，所有光层（雾光、辉光线、竖光、标志描光、眩光）都画在面板同一平面里，跟着面板一起漂。改面板尺寸时要一起改：顶边光线的 y、右缘竖光的 x（1252）、标志描光框（左上 8,12，222×66）。斜放的面板按设计会出画（横屏 2.07 秒右上角到 y −42，竖屏没照到的右下角伸出右边），面板组标了 `data-layout-allow-overflow`。
- `src` 截图铺满 1250×860 的面板、左上对齐：16:9 截图比面板宽，右侧约 18% 被裁掉。标志描光框固定在面板左上，截图的标志不在左上时，描光会落在空白处。
- 深色皮下面板本身也是暗的，光“照出来”的反差很小，所以深色皮多一层跟着光头走的滤色光池（`--k-on-stage` 16%，只在面板里）；白底皮不加，和原版一样。
- `backdrop: off` 只去掉面板外的暗场底：面板和没照到的部分（98.5% 的暗场色）都还在，压在宿主画面上是一块暗面板被光扫过，面板外露出宿主。
- 光层和压暗都是每帧重写的渐变加 blur（最大 34px）：成片用 `render -w 4`。

## 动效与皮的边界

暗场是这张卡的一部分：没照到的面板要沉在黑里，光才是“照出来”的。

属于这张卡的：贴着顶边走的多层辉光线、光头匀速、醒和睡的包络、经过标志时描光、走到右缘点亮竖光再留一线残光、面板斜放而且和光同方向漂。

只是皮：光的颜色（默认第二强调色；要原版那种紫光，宿主设 `--mc-accent-2: #9652ee`）、面板里的内容、面板倾角、重影面板要不要。

和 `slide-spotlight-pan` 的区别：那张面板正对镜头、反方向横移（像镜头右摇），光先爬左缘再拐上顶边，没有醒睡；本卡面板斜放、和光同方向漂，有醒有睡。

## 接进片子

- 变量：`src` 你的界面截图（铺满面板、左上对齐），留空用内置示意界面；`backdrop` 填 `off` 时去掉面板外的暗场底（见已知坑）。
- 对旁白：光 0.83 秒经过左上角的标志，2.07 秒在面板正中，3.43 秒点亮右缘；让说出界面名字的那个词落在 0.8–1.0 秒。4.33 秒后面板已经全暗，下一镜在 4.4–4.67 秒切进。
- 音效：0.13 秒起一个长而轻的 `whoosh`，跟光扫过的 3.9 秒一样长；不要用撞击声。
- 横竖两用：片段写 1920×1080 是横版，1080×1920 是竖版，节奏一样；竖屏场景缩到 0.66、面板滚转 −40°、漂移减半，光从左下往右上爬过主体区。
- 节制：一条片子里光扫类的卡（本卡、`slide-spotlight-pan`、`sheen-sweep`）合计两三次以内。常和 `slide-spotlight-pan` 串成一段界面巡礼：先扫一块斜放的面板，再横摇一块宽面板。
