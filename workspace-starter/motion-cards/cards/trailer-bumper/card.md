这张卡管的不是某个镜头怎么动，而是整段开场怎么接：三切、黑、标题。卡自己画三个示意界面（网格、列表、网格放大到一张卡的特写），真实片子里把这三个换成最抓眼的三个画面时，节拍和黑场照用。

## 命门

1. **三个镜头一样长，零过渡。** 0 / 0.3 / 0.6 秒各一刀硬切，每镜 0.3 秒（9 帧），三镜构图也要拉开：全景网格、全景列表、对着一张卡的 2.2 倍特写。长短不一或加了淡入淡出，读成幻灯片翻页；三镜都是全景，读成同一画面抖了三下。
2. **每镜里面还在慢推。** 每镜从 1.0 倍线性推到 1.04 倍，刚好 0.3 秒。去掉它，三个镜头在 0.3 秒里是三张死静帧；推得太快（超过 1.1 倍）会抢掉切点的节拍。
3. **黑场必须是纯黑、什么都没有。** 0.9 到 1.1 秒共 6 帧，颜色固定 `#000000`，不跟换肤变，也不放字、不放光。放了东西，它就成了第四张字卡，喘息没了；标题从这块黑里亮起来，不是从白底里硬切出来。

## 动作拆解

| 时间 | 谁 | 做什么 | 缓动 |
| --- | --- | --- | --- |
| 0 → 0.3s | 镜头 1：网格全景 | 倍数 1.0 → 1.04 | 线性 |
| 0.3s | 硬切 | 换成镜头 2：列表全景，同样 1.0 → 1.04 | 线性 |
| 0.6s | 硬切 | 换成镜头 3：同一个网格对着中间上方那张卡放大（横屏 2.2 倍，竖屏 2.9 倍），同样 1.0 → 1.04 | 线性 |
| 0.9 → 1.1s | 黑场 | 整屏纯黑，镜头、标题都不在 | 无 |
| 1.1 → 1.5s | 标题底 | 从黑里亮起：柔光底和暗角透明度 0 → 1 | out |
| 1.1 → 1.633s | 标题 | 整块从下方 44px 升到位，同时淡入 | 升 power3.out，淡入 power2.out |
| 1.167 → 1.7s | 眉题 | 淡入 | out |
| 1.3 → 1.9s | 副题 | 淡入 | out |
| 1.1 → 2.1s | 标题字距 | 汉字标题 0.062em → 0em；纯西文标题 0.05em → -0.012em | out |

2.1 秒起所有东西静止，到 4.667 秒共停 2.567 秒。三个镜头之上盖着同一层暗角（强度 0.18）和胶片颗粒，让三镜像同一台摄影机拍的；颗粒每 2 帧换一张。

## 已知坑

- 三个示意界面是卡自己画的、不带文字的灰色版面。真片里的三个镜头要换成最抓眼的真实画面，换完先看三镜是不是真的构图不同。
- 三层镜头都带 `data-layout-allow-overflow`：镜内推近 1.04 倍，画面本来就比容器大 4%，特写的放大层也比容器大。这是有意的，别的节点不要加。
- 特写用 CSS `zoom` 放大（字和线仍然清楚），放大层放在 0,0，位置靠外面一层偏移；`zoom` 会把节点自己的 `left / top` 一起放大，把放大层直接挪位置会差 2.2 倍。
- 竖屏的网格卡片又窄又高（每张约 294px 宽、近 900px 高），特写要放大到 2.9 倍、对准卡片 62% 的高度才看得到柱子，而不是卡片正中的空白。换示意界面时这两个数跟着改。
- 字号按字距最宽的 0.062em 量好再收拢，不会冲出两侧 10%。黑场固定纯黑，换成深色皮也是黑。标题底选“透明”时，黑场在标题出现后 0.4 秒内淡掉，标题落在下面的宿主画面上：深色字要放在偏亮的画面上。

## 动效与皮的边界

属于这张卡的：三切等长、镜内线性推近、三镜构图不同、6 帧纯黑、标题从黑里亮起并且字距收拢、2.1 秒后真静止。这些改了就不是它。

只是皮的：三个示意界面的样子、标题和眉题副题的字、颜色、字体、暗角和颗粒的强度、背景柔光的位置。

和 `flash-cut`（闪白换镜）、`jump-cut-punch-in`（同一构图三次推近）的区别：这张卡是三个不同构图各占 0.3 秒，接一段黑，再出标题，管的是整段开场的结构；前两张只管单个切点。

## 接进片子

- `kicker`（眉题）、`title`（标题）、`sub`（副题）三个变量：眉题和副题可以留空，空了整块不显示，标题留空时三块都不显示，只剩三切和黑场。标题里用 `|` 切意群。
- 长度上限（按版面宽度和字距最宽时推算，折行情形在 `vars-long` 图里看过）：横屏标题约 8 个汉字保持 172px 以上，14 个汉字缩到 99px 还是一行，再长在 96px 折成两行以上；竖屏标题 5 个汉字保持 150px，一行放不下就缩，最小 72px，最多两行，约 22 个汉字，再长折成三行。眉题缩到 28px 后折行，副题缩到 40px 后折行，各最多两行。
- `backdrop`：`on` 标题落在实底柔光上；`off` 时黑场在标题出现后淡掉，标题压在下面的宿主画面上，前面三切和黑场不变，所以这张卡 `overlay: no`。
- 起点对齐旁白里“先看”“接下来”这类开场词，或者整片第 0 秒。三声嘀嗒放在 0 / 0.3 / 0.6 秒，黑场到标题出现之间不放声音。这张卡算整片的开场，不要在它后面 3 秒内再放整屏冲击。
- 常连用 `tracking-settle`、`kicker-headline`：标题出来后接着讲章节标题。
- 竖屏：同一条时间轴，标题放在 12% 到 68% 之间、中线在 40% 处；三个镜头铺满画面，镜头里没有字。
- 渲染：整屏的暗角和颗粒不动 clipPath 和滤镜，直接 `render` 即可。
