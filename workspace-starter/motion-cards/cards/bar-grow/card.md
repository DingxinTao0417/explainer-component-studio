## 命门

1. **强调的那根最后出发。** 不管它排在第几个，普通柱子先按从左到右的顺序长完，它的位置空着；等所有普通柱子都出发了，再过 0.12 秒它才单独冲上来。它按位置顺序跟着长的话，后面长出来的柱子会把视线带走，结论就散了。
2. **只有强调柱过冲。** 普通柱用 power3.out 平稳到位，强调柱用 back.out(1.5) 冲过头再坐回来。全都过冲，画面是一排弹簧，看不出谁是主角。
3. **数值等柱子到了才出现。** 普通柱的数值在柱子到位前 0.1 秒从柱顶弹出，强调柱的数值在它冲到过冲最高点时弹出。一开始就挂着数字的话，观众先读完了数，柱子长不长都无所谓了。

## 动作拆解

默认四根柱子，强调第三根（最高的）。柱宽 320px、间隔 80px，四根合起来 1520px（画面宽的 79%），基线 1680px；五根时脚本把柱宽收到 270px、间隔 64px。结论句 68px，普通数值 96px，强调数值 128px，柱下标签 52px。

| 时间 | 谁 | 做什么 | 缓动 |
| --- | --- | --- | --- |
| 0 → 0.35s | 结论句 | 上移 20px 淡入 | power2.out |
| 0.25s 起，每个隔 0.16s | 柱下标签 | 淡入 0.3s | 线性 |
| 0.35 / 0.51 / 0.67s 起 | 第 1、2、4 根柱子 | 高度 0 → 目标，各用 0.5s | power3.out |
| 0.95 → 1.50s | 第 3 根（强调柱） | 高度 0 → 520px，中途冲过头再坐回 | back.out(1.5) |
| 0.75 / 0.91 / 1.07s | 普通柱的数值 | 缩放 0.3 → 1 并淡入，用 0.28s，原点在数值底部 | back.out(2) |
| 1.20 → 1.48s | 强调柱的数值 | 同上，弹得更狠 | back.out(3.2) |

## 参数手感

| 参数 | 默认 | 调大 | 调小 |
| --- | --- | --- | --- |
| gap 相邻柱子的间隔 | 0.16s | 过 0.3s 变成一根一根地讲，适合旁白逐项点名时用 | 低于 0.08s 像一起长，看不出顺序 |
| grow 普通柱生长时长 | 0.5s | 过 0.9s 拖沓 | 低于 0.3s 柱子是“跳出来”的 |
| focusLag 强调柱比最后一根普通柱晚出发多少 | 0.12s | 过 0.4s 像单独又演了一段 | 0 时它只是队伍里的最后一根，主次变弱 |
| focusGrow 强调柱生长时长 | 0.55s | 过 0.9s 过冲变成慢悠悠的晃 | 低于 0.35s 像弹出来的，不像长出来的 |
| maxH 最高柱的高度 | 520px | 过 560px 强调柱的数值过冲时会顶到结论句 | 低于 350px 柱子之间的差距看不出来，图表也缩回画面下半 |
| popLead 数值提前量 | 0.1s | 过 0.25s 数值比柱子先到 | 0 时数值像事后贴上去的 |

## 已知坑

- 第一版是让强调柱按位置顺序出发、只把时长拉长到最后落定。结果缓出曲线让它在 1.0 秒就已经长到顶了，比右边那根普通柱还早，“最后到”只存在于数字里。改成最后出发才真的最后到。
- 强调柱过冲时，柱顶的数值会跟着被顶高三十多像素。最高柱上方必须留出这段空间，现在图表区高 750px、柱子最高 520px、强调数值占 160px，剩 70px，够用；把 `maxH` 调大前先算这笔账。
- 用 `scaleY` 长柱子的话，圆角会被拉扁，数值也没法跟着柱顶走。这里改的是高度，数值排在柱子上面，自然被顶上去。
- 柱子不从 0 开始（截断纵轴）会把 18 和 27 的差距夸大。这张卡的柱高永远按“数值 ÷ 最大值”算，不提供截断。
- 标签 52px，列宽 320px：超过六个字会撑出列宽、和邻居连在一起；五根柱子时列宽 270px，标签最多五个字。标签写短，细节交给旁白。
- 数值超过三位（如 `1284`）加单位后，128px 的强调数值会比 320px 的柱子宽，压到邻居头上。大数先换算成“1.3 千”，或者把单位留空。
- 最小值太小（不到最大值的 2%）时柱子只剩一条线，脚本给了 8px 的保底高度。这种悬殊的对比更适合 `stat-compare`。

## 动效与皮的边界

属于这张卡的：从同一条基线依次长出、强调柱最后出发并且独自过冲、数值在柱子到位时才从柱顶弹出。

只是皮：柱子宽度、圆角、间距、非强调柱的灰度、数值和标签的字号、结论句放上面还是不放、基线的粗细。

## 接进片子

- 变量：`values` 用 `|` 分隔的 3–5 个数；`labels` 对应的标签；`unit` 数值后的小单位（可空）；`focus` 强调第几根，填 0 自动取最高的；`headline` 结论句；`backdrop`。
- 对齐：强调柱数值弹出的时刻（默认 1.20 秒）对旁白说出结论的那个词。柱子多一根，这个时刻晚 0.16 秒。
- 音效：整段生长配一个 1 秒左右的上扬声，强调柱的数值弹出时加一个“啵”。
- 一屏只留一个结论。想同时强调最高和最低，就拆成两屏。
- 示例数字是编的，结论句里标了“示例数据”。
