## 命门

1. **镜头贴面和元素落下要同时有。** 界面一直斜躺着（横屏前倾 14°、侧转 28°），镜头沿列表往下滑；字和行同时从空中落回来。只有贴面滑行，读成一张斜着滚动的截图（那是 `tilt-page-3d`）；只有落下、镜头不动，读成普通的逐行入场。
2. **影子跟着高度变，落地归零。** 悬空时字的下方有一份同形的软影，离得越高，影子离得越远、越大、越糊；落到界面上那一刻影子缩回字底下，贴着字消失。影子恒定不变，悬空的字像贴纸；没有影子，读成往左上平移了一下。
3. **错开起点，下落过程互相重叠。** 相邻两行落地相隔 0.15 秒，每行下落要 0.57 秒，所以同一时刻总有三四行在半空。全部同一帧落下读作开关；一行落完下一行才动，节奏变成一条一条的念稿；不按镜头经过的先后落，读作出错。

## 动作拆解

时间全部按原版一段 50 帧（`CFG.seg` = 1.667 秒）的比例算，卡从 0.2 秒开始这一段。

| 时间 | 谁 | 做什么 | 缓动 |
| --- | --- | --- | --- |
| 0 → 0.2s | 镜头 | 停着；所有元素在最高处，第一组（标签栏）在 0 秒开始下落 | — |
| 0.2 → 1.867s | 镜头 | 沿列表往下滑（横屏注视点从第一行顶边往上 90px 滑到最后一行中线往上 190px，默认四行时是界面上 y 533 → 1028，走 495px，同时左移 220px），滚转跟着同一条曲线从 −6° 转到 −4° | 前 0.5 秒二次加速、中段匀速、后 0.5 秒二次减速 |
| 0 → 0.567s | 标签栏 | 从 150px 高处落回 | bezier(0.5, 0.05, 0.6, 1) |
| 0.167 → 0.733s | 视图切换行 | 从 150px 落回 | 同上 |
| 0.367 → 0.933s | 分组标签 | 从 160px 落回 | 同上 |
| 0.533 → 1.1s | 表头 | 从 150px 落回 | 同上 |
| 0.667 → 1.233s 起，每行晚 0.15s | 任务行 | 从 160px 落回，四行最后一行 1.683s 落地 | 同上 |
| 1.867 → 3s | 全部 | 静止 1.13 秒 | — |

悬空高度 h 时：元素在界面上往左上偏 (0.34h, 0.78h)。影子是这一块的一份副本，留在原位，往右下偏 (0.22h, 0.42h)，再以这一块的中心放大 1 + 0.0011h 倍（h = 160 时 1.18 倍），模糊 2 + 0.09h px（CSS `blur` 的标准差），浓度 0.08 + 0.0026h（最多 0.22，浅色皮再乘 1.5），h 小于 1.5px 时去掉。每一块都横跨界面全宽（横屏 2660–2900px），中心在界面正中，所以左半边的字，影子被放大推向左边：横屏任务名在 h = 160 时，影子在悬空的字下方约 190px、偏左约 100px；竖屏界面窄，影子偏右约 50px。镜头：透视 1050px，横屏放大 1.05 倍。原版注视点是界面上 y 620 → 1240（走 620px，落定时最后一行在画面正中，下半屏是空的）；这里起点抬高 87px、终点抬高 212px，落定画面四行都在框里，代价是镜头少走 1/5，巡航慢 20%。竖屏前倾 30°、侧转 16°、放大 0.95 倍，注视点从第一行顶边往上 220px 滑到最后一行中线往上 345px。画面焦点在横屏 (46%, 50%)、竖屏 (50%, 44%)，椭圆 58% × 52% 的 34% 以内清楚，往外模糊到 15px。

## 参数手感

| 参数（脚本顶部） | 默认 | 调大 | 调小 |
| --- | --- | --- | --- |
| CFG.seg 一段时长 | 1.667s | 2.5s 以上像在慢慢看界面，落下变轻飘；整段跟着拉长，slot 要一起加 | 1.2s 以下落下太急，三四行同时砸下来 |
| CFG.fall 下落占一段的比例 | 0.34（0.567s） | 0.5 以上半空的字太多，画面糊成一片 | 0.2 以下落下像闪现，看不出加速 |
| CFG.rowGap 行与行的间隔 | 0.09（0.15s） | 0.2 以上一行落完下一行才动，见命门 3 | 0 时全部同一帧落地，读作开关 |
| CFG.lift / rowLift 悬空高度 | 150 / 160px | 250px 以上落地砸得太重，影子离字太远认不出是谁的 | 80px 以下影子和位移都读不出来 |
| LAND.ry / rx 倾角 | 28° / 14° | ry 过 40° 行的右半截挤成一条线 | ry 低于 15° 贴面感没了，像平着滚动 |
| CSS `.gf-dof` 模糊 | 15px | 25px 以上四周糊成雾，看不出是界面 | 0 时整屏清楚，读作平面滚动 |

## 已知坑

- 暗角和焦外模糊盖在整个界面上，检查会报每个字 `text_occluded`。脚本给界面里每个 `span` 加了 `data-layout-allow-occlusion`（标在父层无效，实测）；往界面里加字时也要加。
- 检查按压暗、虚化后的实际底色算对比度。界面右半边（远端加暗角加焦外）上，强调色和 `--k-muted` 的字只有 2.3–2.9:1，横屏那一遍报错；所以截止日期和表头用 `--k-ink`，分组标签做成实心强调色块配 `--k-on-accent`，视图切换里「列表」的字色是强调色混 30% 墨色（横屏 0.11 秒它在左上角的暗角和焦外里，纯强调色只有 1.96:1）。远端别再放强调色或灰色的字。浅色皮的远端压暗是界面宽度 50% 处起、75% 处 20%、边上 40%，暗角横屏 0.38、竖屏 0.3（竖屏 0.38 时「列表」只有 2.99:1）；原版是 34% 处起、0.22 / 0.5，暗角 0.62，压在白色界面上发脏，所以减轻了，深色皮照原版。
- 深色皮下影子是近黑的，压在深色界面上几乎看不见，悬空只能靠往左上的位移读出来，命门 2 打了折扣（`skinshot` 深色皮横竖两遍实测）。
- 竖屏的取景按 4 行调过：落定时整张列表在 12%–68% 之间。5 行时注视点跟着最后一行往下走，顶上的标签栏会进 12% 以上的顶栏；竖屏名称超过 6 个汉字时所有行一起缩小，9 个汉字缩到 40px，再长会把头像和日期往右挤。
- 影子是脚本给每块 `cloneNode` 出来的副本，所有着色部分用 CSS 换成 `--gf-shade`；副本里的字标了 `data-layout-allow-overlap`（和悬空的字叠在一起是有意的），不标会报 `content_overlap`。新加的界面块放进脚本的 `fl` 列表就自动有影子。不要改回 `drop-shadow`：它没法以整块中心放大，而且它的第三个值在 Chrome 里也是标准差，照 box-shadow 的半径习惯写成 2 倍就糊掉了。
- 焦外模糊用的是 `backdrop-filter`，影子副本每帧改 `blur`。成片用 `render -w 4`（SPEC「六」）；实测 4 秒的验证工程 4 个进程渲染约 10 秒。
- 横屏 `backdrop: off` 时界面平面仍盖住画面约 97%，宿主画面只在右上角露出一个三角，等于一块整屏的板；真正“压在画面上”只有竖屏（界面上方和两侧露出宿主画面）。

## 动效与皮的边界

属于这张卡的：界面一直斜躺、镜头贴着它滑；元素悬空时左上偏，影子留在原位右下偏并放大，两者都随高度线性收拢，落地影归零；按镜头经过的先后落地、起点错开而过程重叠；下落先慢后快、末端软着陆；前后两头缓、中段匀速的巡航，带 2° 的慢滚转；画面四周的焦外模糊。

和 `tilt-page-3d` 的区别：那张是一整张长网页图倾斜着被镜头滑过，最后立起来转正，主角是“页面很长”；这张界面始终斜着，主角是界面上的东西从空中落回来，缺了落下就只是那张卡的弱化版。

只是皮、可以换的：任务列表的内容和样式（标签栏、视图切换、分组标签、表头、任务行都可以换成别的界面块，只要每块单独落）、强调色、左边缘的缘光、地面和暗角的深浅、有没有实底。

## 接进片子

- 变量：`items` 任务行，用 `|` 分隔，2–5 条，按落地先后排，每条最好不超过 6 个汉字（竖屏）；`label` 只改分组标签（不换行，8 个汉字实测正常），截止列固定是今天、今天、明天、周五、下周；`backdrop` 填 `off` 时去掉地面和暗角，焦外模糊只作用在这张卡自己的界面上，不会糊到下面的素材，但界面外缘在素材上是清楚的。竖屏时界面浮在宿主画面上；横屏时界面几乎铺满画面，只有右上角露出宿主画面（见已知坑）。
- 起始时间：让最后一行落地（卡内 1.683 秒）对上旁白说最后一项的词；只说“这个功能区”时，让镜头起步（0.2 秒）对上这句话的开头。
- 音效：镜头起步 0.2 秒一个轻的 `whoosh`；要点名每一行时，在行落地的 1.233、1.383、1.533、1.683 秒各一个轻 `tick`，别给前面四组也加。
- 横竖两用：片段写 `data-width="1920" data-height="1080"` 是横版，写 `1080` × `1920` 是竖版；变量和节奏不变，竖屏的倾角和取景由卡自己换。
- 常和 `tilt-page-3d`、`screen-push-focus` 连用：先用这张卡交代“界面在这儿、长这样”，再用 `screen-push-focus` 推到要操作的那一行。
