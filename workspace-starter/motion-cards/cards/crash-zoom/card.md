## 命门

1. **0.2 秒，一路加速。** 冲的阶段用 `power2.in`，最快的一帧是停下前的那一帧，所以读成“撞上去”。换成缓出（先快后慢）就是一次普通的推近；拉长到 0.4 秒以上就只是“放大”。
2. **幅度要大。** 默认 2.4 倍。急推靠的是画面内容在几帧里整个换掉，1.3 倍的急推看起来像画面抖了一下。
3. **拖影只在最快的两帧。** 径向拖影在停下前一帧最浓，停下那一帧必须已经干净。拖影留到停稳之后，读成的是重影、没对上焦，不是速度。

## 动作拆解

| 时间（相对 hit） | 谁 | 做什么 | 缓动 |
| --- | --- | --- | --- |
| 0 之前 | 镜头 | 全貌，静止 | — |
| 0 → 0.2s | 镜头 | 缩放 1 → 2.568（2.4 × 1.07），目标点移到画面中央 | power2.in |
| 0.047 → 0.167s | 4 层拖影 | 透明度 0 → 0.5 / 0.4 / 0.3 / 0.22，各自以目标点为原点放大到 1.025 / 1.05 / 1.075 / 1.1 | power1.in |
| 0.167 → 0.2s | 4 层拖影 | 透明度归零 | none |
| 0.2 → 0.46s | 镜头 | 缩放 2.568 → 2.4，位移跟着回正 | power2.out |

拖影是同一张图的 4 份副本，带 2px 模糊，围着目标点逐级放大：目标点本身不动、保持清楚，离它越远错位越大，这就是径向模糊的样子。

## 参数手感

| 参数 | 默认 | 调大 | 调小 |
| --- | --- | --- | --- |
| zoom 落定倍数（变量） | 2.4 | 过 3.5 倍画面发虚，而且目标周围没有参照物 | 低于 1.6 冲击不够，改用慢一点的推近 |
| rush 冲的时长 | 0.2s | 0.3s 还算快推，过 0.4s 就不是“急”了 | 0.13s（4 帧）是下限，再短只看到跳切 |
| over 过冲 | 1.07 | 过 1.12 像弹簧，显得轻浮 | 1.0 时停得很硬，像剪辑软件里的关键帧 |
| settle 收回时长 | 0.26s | 过 0.4s 像没刹住 | 低于 0.15s 过冲看不见 |
| smear 拖影级差 | 2.5% 一级，共 4 级 | 一级超过 5% 能数出几个重影 | 去掉拖影也成立，只是少了速度感 |
| hit 开始时间（变量） | 0.8s | — | 低于 0.4s 观众还没看清全貌，不知道是从哪里冲过来的 |

## 已知坑

- 第一版只有 3 层拖影，级差 5%–7%（1.05 / 1.11 / 1.18），连拍图上每个字清清楚楚变成三个，像印刷套色错位。改成 4 层、每级 2.5%，再给副本加 2px 模糊才连成一片。
- 第一版拖影的最浓点正好在镜头停下的那一帧，接着 0.13 秒才淡完：画面已经停了，上面还盖着重影。现在最浓点提前一帧，停下那一帧归零。
- 目标点靠边时不居中：第一版默认目标是右侧的状态徽章（fx 0.88），2.4 倍下镜头被画面边界挡住，徽章最后停在画面右侧四分之一处，“就是这里”指偏了。目标的可居中范围是 0.5 ÷ zoom 到 1 − 0.5 ÷ zoom（2.4 倍时是 0.21–0.79），超出就降倍数。
- 放大后的镜头层大半在画面外，检查报过 `escaped_container`，包裹层上的 `data-layout-allow-overflow` 是为它加的。
- 回收阶段不能用带回弹的缓动：位移和缩放按同一进度插值，回弹会让进度越过终点，目标贴边时那一瞬间会露出底色。这里用的是没有回弹的 `power2.out`，过冲由前一段冲过头来做。

## 动效与皮的边界

属于这张卡的：到点才动、0.2 秒的加速冲入、冲过头再收、只出现在最快两帧的径向拖影、落定后目标在画面中央。

只是皮：被拍的内容、落定倍数的具体值、拖影层数、有没有实底、落定后叠什么标注。

## 接进片子

- 变量：`src` 画面地址，`fx` / `fy` 目标点（0–1），`zoom` 落定倍数，`hit` 开始冲的秒数，`backdrop`。
- 对旁白：`hit` 填“这里”“这一行”那个词出口的时间减 0.2 秒，让镜头在词说完时撞到位。
- 音效：`hit` 处一个 0.2 秒的短促掠过声，`hit + 0.2` 处一个轻的撞击声。
- 连用：前面用 slow-push 铺垫，反差最大；落定后接荧光笔或下划线类的卡标出具体的字；离开时用 pull-reveal 退回全貌。一条片子里用三次以内。
