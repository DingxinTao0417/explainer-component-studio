## 命门

1. **左列只在换词的那一刻动，而且正好滚一页。** 每个切词点起 0.6 秒滚 635px（页高 530 加间距 105），其余时间零位移。让它一直慢慢飘，左列就退成背景装饰，换词也没有“咔哒”一下的感觉；滚过头或不够一页，下一张页面停不到焦点位上，读成故障。
2. **词块的中线就是当前页的中线。** 两行词各占 154px 的行盒，从 y=386 排到 694，中线 540；焦点页从 y=275 排到 805，中线也是 540。差到 8px 以上就看得出歪，整个“一边是证据、一边是论点”的版式会塌。
3. **旧词先走，新词后到，不叠在一起。** 旧词在切点前 0.333 秒灰掉，切点起 0.267 秒内向上升出；新词的第一个字切点后 0.233 秒才从遮罩下沿升起，这时旧词只剩一条淡影。同一时刻交叉，会出现旧词新词叠成一个怪词的画面。

## 动作拆解

三个词的默认时刻（秒）。切点 sw = 0.533 / 2.2 / 3.8，第一个动词在 0.533 之前还没出现，只有主语和第 0 页。

| 时间 | 谁 | 做什么 | 缓动 |
| --- | --- | --- | --- |
| 0 → 0.533 | 引线和圆点 | 引线从焦点页右缘画向词块，圆点同时淡入 | snappy |
| sw → sw+0.6 | 左列页面 | 整列上移一页 635px；峰值速度约 2860px/s，叠纵向运动模糊（上限 10px），走完 95% 用 0.44 秒 | swift |
| 全程 | 邻页 | 离焦点越远越暗、越小、越糊：一页之外压暗 68%、缩到 0.94、模糊 3px | 随位置 |
| sw−0.333 → sw | 旧动词 | 墨色灰掉，到 40% 墨色 | smooth |
| sw → sw+0.267 | 旧动词、旧注脚 | 动词上移 139px 并降到 40% 透明度；注脚用 0.233 秒上移 10px 淡出 | exit |
| sw → sw+0.2 | 引线 | 收回到 0 | exit |
| sw+0.233 起 | 新动词 | 逐字从遮罩下沿升起，每字 0.533 秒，相隔 0.04 秒，最后到的是强调色句点 | snappy |
| sw+0.333 → sw+0.867 | 引线 | 重新画出 | snappy |
| sw+0.433 → sw+0.9 | 新注脚 | 从下方 14px 升起并淡入 | snappy |
| 0 → 全片结束 | 整个画面 | 1 → 1.02 极慢推近 | swift |

第三个词的最后一个字在 4.69 秒落稳，注脚 4.70 秒，页面 4.4 秒就停了，到 6.0 秒结束还停 1.3 秒。

## 参数手感

| 参数（脚本顶部） | 默认 | 调大 | 调小 |
| --- | --- | --- | --- |
| CFG.sw 切点 | 0.533 / 2.2 / 3.8（第四个 5.4） | 一个词停超过 2.5 秒就有点空，旁白要念长句时才用 | 两个切点间隔低于 1.2 秒，上一个词还没读完就被换掉 |
| CFG.step 滚页时长 | 0.6s | 过 0.9 秒像在滑动，丢了“咔哒” | 低于 0.35 秒速度太猛，模糊糊成一片 |
| G.dim 邻页压暗 | 0.68 | 过 0.85 邻页只剩一个影子，不像页面 | 低于 0.4 邻页和焦点页抢戏 |
| G.blur 邻页模糊 | 3px | 过 5px 看不出那是一页页面 | 0 时景深感没了 |
| CFG.letterGap 字间隔 | 0.04s | 过 0.1 秒一个一个蹦，读得慢 | 0 时整词一起升，没有逐字的节奏 |
| CFG.grey 灰化 | 0.333s | 过 0.5 秒旧词灰太久，新词空等 | 低于 0.15 秒来不及读出“要被换了” |
| CFG.push 慢推 | 0.02 | 过 0.05 页面边缘明显在漂，对齐线跟着变化 | 0 时只剩换词时动，片尾偏死 |

## 已知坑

- 词块只有 628px 宽，主语和动词都一行放、不折行：缩到 64px 还放不下，字会伸出右边。横屏动词最多约 9 个汉字（3–4 个字最好看，8 个字缩到约 72px）、西文约 14 个字母，主语同理。注脚最多两行、每行约 15 个汉字（40px 不再缩），超过约 30 个字第三行会往下伸，先缩短文案。
- 默认左列画的是无字的示意页面（圆角条代替文字），静态页只有一张空白页。换成截图时每张铺满 940×530，比例差得多会被裁；亮暗相间要自己挑图，相邻两张同色系就看不出滚了一页，不会报错。
- 主语用次级色（`--k-muted`），`backdrop: off` 压在花哨画面上会读不清，要么换深一点的 `--mc-muted`，要么留空主语。
- 词数不同总长不同：2 个词 4.4 秒、3 个词 6.0 秒、4 个词 7.6 秒（`slot` 按 3 个词写），落定后都停 1.3 秒以上。
- 左列和邻页按设计伸出画面上下，`.wr-film` 带 `data-layout-allow-overflow`，只标这一个节点。只做横屏：词块和页面靠同一条中线对齐，竖屏上下叠起来后对齐不成立；挂进竖屏项目会被 `use` 拒绝。成片里有 blur 和 clip-path 在动，渲染用 `render -w 4`。

## 动效与皮的边界

属于这张卡的：左列整页步进（平时零位移）、邻页按距离压暗缩小虚化、词块中线与页面中线对齐、旧词先出新词后进且逐字升起、引线收回再画出、序号和注脚随动词同步换。

只是皮的：页面里画什么（示意页面或自己的截图）、主语和动词的字、注脚的字、强调色（引线、圆点、句点、序号）、衬线字体、底色。`backdrop: off` 时去掉实底、主光、补光、暗角和颗粒，邻页改用透明度变淡，宿主画面能透出来。

和 `filmstrip-pass` 不同：那张是图片带匀速横扫、过中间放大，没有字；这张是竖列、一格一格停、字和图互相作证。和 `triptych-relay` 不同：那张三格宽窄互换，图不动；这张图一页页换，主角是词。

## 接进片子

- `subject` 是不变的主语（第一行），可以留空：留空时动词一行单独对齐页面中线。`verbs` 用 `|` 分 2–4 个词，第 k 个词停在第 k 页（页 0 是开场页）。`notes` 用 `|` 分，和词一一对应，某一段留空就没有注脚。
- `shots` 填截图路径（从项目根目录写起，`|` 分隔，第 k 张配第 k 个词，比词多的会轮回使用）；留空画示意页面。
- 起点对齐旁白：切点 sw 对着旁白里每个新词开口的前 0.2 秒，词在第一个字升起后 0.2 秒内读出来最顺。三个词以外用 `verbs` 的个数自动取前 n 个切点，要改间隔就改 `CFG.sw`。
- 音效：`step1`–`step3` 对着三个切点 0.533 / 2.2 / 3.8 秒放 `tick`；第四个词的切点是 5.4 秒。
- 横屏专用，竖屏项目里别用。常和 `word-slot`（词槽接力）、`filmstrip-pass`（快速带过）连用。
- 成片渲染用 `render -w 4`。这张卡不算整屏冲击，可以和别的特效同片出现。
