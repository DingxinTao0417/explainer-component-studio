## 命门

1. **每一行踩着旁白出来。** 一行字在主持人说出它第一个字的那一刻升起（`cues`）。字比话早，观众先读完再听，口播成了念稿；字比话晚，像字幕跟不上。
2. **荧光笔等金句站稳了再下笔。** 金句升起后 0.3 秒才开始划。跟着字一起出来，笔读成字的入场装饰，不是“这句要记住”。
3. **只划一句。** 铺垫在下笔的同时退成次要色，整屏只剩一个重点。两句都划、或者铺垫还是正文色，观众不知道哪句是结论。

## 动作拆解

主持人放在一个 1100×900 的框里，贴着画面底边，人脸中线在 x=1460（人在左时 460）；字在另一侧 760px 宽的一栏里，左边距 140（人在左时 1020），三行时顶在 y=300，两行时往下挪 50。

| 时间 | 谁 | 做什么 | 缓动 |
| --- | --- | --- | --- |
| 0 起 | 主持人 | 一直在，视频从第 0 秒开始播 | — |
| 0.3 → 0.75s | 第一行 | 上移 26px 淡入，64px | power3.out |
| 1.1 → 1.55s | 第二行 | 同上 | power3.out |
| 1.9 → 2.35s | 金句 | 同上；字重加粗，最大 72px | power3.out |
| 2.2 → 2.7s | 荧光笔 | 从左往右展开，盖住金句下半截，比字两头各多出 10px | power2.out |
| 2.2 → 2.6s | 铺垫两行 | 从正文色退成次要色 | power1.out |
| 2.7s 起 | 整屏 | 不再动，停到这一镜结束 | — |

## 参数手感

| 参数（脚本顶部 CFG） | 默认 | 调大 | 调小 |
| --- | --- | --- | --- |
| penLag 金句升起后多久下笔 | 0.3s | 过 0.6 观众已经读完了，笔来得像补一句 | 0 时笔和字一起出来，像入场装饰 |
| pen 荧光笔划多久 | 0.5s | 过 0.9 像慢慢涂，拖住了这一镜的收尾 | 低于 0.25 一闪而过，看不出是划出来的 |
| gold 金句最大字号 | 72px | 过 84 和铺垫差太多，像两张卡拼在一起 | 和铺垫一样大时，金句只靠荧光笔撑 |
| rise 每行升起 | 0.45s | 过 0.7 字慢慢飘上来，跟不上语速 | 低于 0.25 像闪现 |
| minGap 两行最小间隔 | 0.45s | 旁白说得快时，后面的行被推得越来越晚 | 低于 0.3 两行几乎同时升起，读成一块 |

## 已知坑

- `cues` 只给一个数时，后面的行按 0.8 秒一行往后排；给了两个以上，按它们的平均间隔补齐。两行挨得比 0.45 秒还近，后一行会被推后。
- 金句超过 10 个字会按 760px 一栏缩字号：11 个字 69px，14 个字只剩 54px。再长就删字，或者拆成两屏。
- 默认字是深色的正文色。`backdrop` 写 `off` 压在偏暗的实拍上时字会看不清，这时给项目换深色皮（`--mc-ink` 用浅色）。
- 卡里的人物视频每次挂载都从第 0 秒播，而且同一张卡在一个工程里只有第一次挂载的视频有画面（HyperFrames 0.8.174 实测，换文件、改 id 都不行；图片不受影响）。一段口播要连续对口型、或者同一张卡要用两次以上时，把主持人视频放在主时间轴的一层（写法见 README「人物卡」），卡里 `host` 留空、`backdrop` 写 `off`。只用一次时可以直接填 `host`，素材至少和这一镜一样长：`episode.py media <项目> <原片> --start <秒> --duration <秒>` 截一段放进工程。
- `mark` 指到第一行时，金句先出来，后面的行一出现就是次要色。这是有意的：后面的话是给金句做注解的。

## 动效与皮的边界

属于这张卡的：人和字各占一边、每行踩着旁白出现、只有金句被划、等金句落定再划、铺垫同时退下去、划完整屏停住。

只是皮：字号、荧光笔的颜色深浅和高低、铺垫退成什么颜色、人站哪边、底色、行距。

## 接进片子

- `lines`：铺垫和金句，用 `|` 分开，最多三行；默认最后一行是金句，`mark` 写 1–3 可以指定别的行。
- `cues`：每行出现的秒数，相对这一镜的起点，对齐主持人说出这一行第一个字的时刻（`align.py find` 查）。
- `host`：本期主持人的透明底视频或图片，从项目根目录写起；`hostKind` 默认按扩展名自动判断（png、jpg、webp 当图片，其余当视频）；主持人已经在下面一层铺满播放时把 `host` 留空（或者 `hostKind` 写 `none`），`backdrop` 写 `off`，这张卡只留字。
- `side`：人在画面哪边，`left` 时字放到右边。
- 音效：荧光笔下笔时一个短 draw；金句本身不配音效，把重音留给旁白。
- 常接在 `host-arrows-focus` 后面：先指住一个重点，再收成一句结论。也适合作为一段口播的最后一镜，后面直接切章节。
