## 命门

1. **一个接一个，不是一起。** 三个气泡相隔 0.55 秒。一起弹出来是一张“观众评论”的静态图；有先后，才像是七嘴八舌、越问越多。
2. **从尖角里长出来。** 每个气泡的变形原点在它自己的尖角上，从 0 弹到 1.14 再回到 1。从中心放大的气泡是一个弹窗，和头没有关系；从尖角长，才是“这句话是冲着这个人说的”。
3. **在头边，不在头上。** 三个气泡分别在头的右上、左侧、右侧偏下，离头的边缘留 30px 以上。压住脸，观众就看不到主持人被问到时的表情，这张卡最好看的部分没了。

## 动作拆解

三个气泡各自的起点是 0.40 / 0.95 / 1.50 秒，下面的时间相对各自的起点。

| 时间 | 谁 | 做什么 | 缓动 |
| --- | --- | --- | --- |
| 0 → 0.16s | 气泡 | 从尖角处 0 → 1.14，角度从 3 倍倾角甩到反向 | power3.out |
| 0.04 → 0.13s | 人物 | 下沉 10px | power2.out |
| 0.13 → 0.43s | 人物 | 回到原位 | power2.out |
| 0.16 → 0.46s | 气泡 | 1.14 → 1，角度落到自己的倾角（-3° / 2.5° / -2°） | back.out(3) |
| 0.46 → 1.30s | 气泡 | 挂着，慢慢上浮 10px | 线性 |
| 1.30 → 1.80s | 气泡 | 上飘 110px，横向漂 ±40px | power1.in |
| 1.50 → 1.80s | 气泡 | 缩到 0 | power2.in |

## 参数手感

| 参数 | 默认 | 调大 | 调小 |
| --- | --- | --- | --- |
| gap（变量）间隔 | 0.55s | 过 1 秒变成一问一答的节奏，适合旁白逐条回应 | 低于 0.3s 等于同时出 |
| stay（变量）停留 | 1.3s | 每条超过 6 个字时给到 1.8 秒 | 低于 0.8s 读不完 |
| peak 弹出峰值 | 1.14 | 过 1.25 气泡会撞到头 | 1.0 时没有弹性，像贴纸 |
| nod 人物下沉 | 10px | 过 20px 像被砸了一下，适合搞笑片 | 0 时人是一张不动的图，气泡和他没关系 |
| rise 飘走距离 | 110px | 过 200px 第一个气泡会飘出画面顶边再消失 | 低于 50px 看不出是飘走 |

## 已知坑

- 气泡是深色字压在浅色泡上，所以进出场都不用淡入淡出：泡淡到一半时，深字压在透出来的深底上，对比度掉到不合格。进场是不透明地从 0 放大，退场是不透明地缩到 0。
- 人物下沉用的是向下的位移，人物图的底边要贴着或伸出画面底边。如果人物是悬空的半身图，下沉会看起来像整个人往下掉，改成缩放 0.99 更稳。
- 每个气泡的位置是按“头在画面正中、高度 380px、头宽 270px”写死的。人物偏一侧时，三个气泡的 `left / right / top` 要跟着整体平移。
- 每条 8 个字以内。右侧的气泡从 1130px 起，58px 的字超过 11 个就伸出画面右边。
- 只有两条时用的是右上和左侧两个位置，第三个位置空着，画面右下会偏空，可以把人物往右挪一点。

## 动效与皮的边界

属于这张卡的：相隔半秒接连出现；从尖角处弹出并带一点甩动；人物随每个气泡沉一下；各自挂够时间后向上飘走缩没。

只是皮：气泡的颜色（默认两白一黄）、圆角、尖角的形状、字体、倾角的具体度数、人物身后的底形。气泡里换成表情符号或问号也成立。

## 接进片子

- 变量：`host` 人物图，压在实拍上时留空；`bubbles` 气泡里的话，用 `|` 分开，2–3 条；`gap` 相邻两个的间隔；`stay` 每个停多久；`backdrop`。
- 开始时间：卡的 0.4 秒对齐主持人那句反常识的话说完的瞬间。旁白要逐条念出气泡内容时，把 `gap` 改成每条念出的间隔。
- 音效：每个气泡弹出的那一帧一个短的弹出声，三个的音高可以依次升高。
- 常见接法：气泡飘走后，主持人用 `word-punch` 给出回答里的重音词。
