## 命门

1. **钉在角上缩。** 小窗用 `right/bottom`（或 `left/top`）钉住目标角，只改宽高和 60px 的边距。它是朝着那个角收拢的，路径是一条直线。用 `left/top` 从画面中心算位移的话，宽高和位置的缓动稍有不同，小窗就会在半路画一个 S 形。
2. **先小后弹。** 0.6 → 1.1s 缩到最终尺寸的 0.9 倍，1.1 → 1.38s 再弹到位。直接缩到最终尺寸停住，像一次普通的缩放；多这一下，才有“卡进停靠位”的感觉。
3. **缩完就让出主画面。** 底下的内容在 0.75s 就开始从 1.05 缩回 1、变实，不等小窗落定。等小窗完全停稳再出主内容，中间会空出将近半秒什么都没有的画面。

## 动作拆解

| 时间 | 谁 | 做什么 | 缓动 |
| --- | --- | --- | --- |
| 0 → 3.4s | 小窗里的图 | 一直缓慢推近 1 → 1.08（代替“视频还在放”） | 线性 |
| 0 → 0.60s | 满屏画面 | 停住 | — |
| 0.60 → 1.10s | 小窗 | 宽高 1920×1080 → 504×284（最终的 0.9 倍），圆角 0 → 22，阴影出现 | power3.inOut |
| 0.68 → 1.43s | 小窗 | 离两条画面边的距离 0 → 60px，略过头再回来 | back.out(1.7) |
| 0.70 → 0.95s | 白边 | 透明 → 不透明 | power1.out |
| 0.75 → 1.35s | 让出来的主内容 | 缩放 1.05 → 1，透明度 0.4 → 1 | power3.out |
| 1.10 → 1.38s | 小窗 | 宽高弹到 560×315 | back.out(2.4) |

## 参数手感

| 参数 | 默认 | 调大 | 调小 |
| --- | --- | --- | --- |
| at 满屏停留 | 0.6s | 这段本来就是前一个镜头的延续，可以随便长 | 0 时一上来就在缩，观众没看清原画面 |
| shrink 收拢时长 | 0.5s | 过 0.8s 像慢慢被挤走 | 低于 0.3s 看不出它去了哪个角 |
| under 先缩到几成 | 0.9 | 1.0 就没有弹的那一下 | 低于 0.8 弹得太大，小窗像在跳 |
| size 小窗宽度（变量） | 560px | 过 700px 会压到让出来的标题 | 低于 400px 里面的内容基本看不清，只剩“还在放”的意思 |
| margin 离边距离 | 60px | 过 100px 小窗像悬在半空 | 低于 30px 贴边，阴影被画面边切掉 |
| drift 图的缓慢推近 | 1.08 | 过 1.15 小窗里的图明显在动，抢戏 | 1.0 小窗是一张定格图 |

## 已知坑

- 让出来的标题在前 0.6 秒被满屏画面完全盖着，`verify` 会把它当成“字被挡住”。三行字都加了 `data-layout-allow-occlusion`，这是有意的叠压。
- 白边是单独的一层，盖在图上淡入。直接给小窗加 `border` 并让它从 0 长到 6px，图会被边框往里挤，收拢过程中画面内容在抖。
- 小窗是 16:9（560×315），示例图是 16:10，上下各裁掉一点；满屏时同样是裁过的，所以前后一致。素材是别的比例时，改脚本里 `w * 9 / 16` 这个算式。
- 选左边的两个角（`bl` / `tl`）时，让出来的文字会自动改成靠右对齐，避开小窗。自己换了主内容的版式，要按小窗的位置（宽 `size`、高约 `size × 0.56`、离边 60px）把那一块空出来。
- 这张卡的“满屏画面”是一张图。前一个镜头是视频时，取它最后一帧存成图填进 `srcs`，并把卡的开始对在那一帧上，接缝才看不出来。

## 动效与皮的边界

属于这张卡的：钉住一个角收拢、先缩过头再弹到位、收拢途中带上边框圆角阴影（从“画面”变成“一个窗口”）、主内容在收拢中途就接上来。

只是皮：哪个角、小窗多大、白边的颜色和粗细、圆角、让出来的主内容是标题还是别的卡、图在小窗里要不要缓慢推近。

## 接进片子

- 变量：`srcs` 满屏那张图（只用第一张）；`corner` 缩到哪个角；`size` 小窗宽度；`kicker` / `title` / `note` 是演示用的主内容，三个都留空就只剩小窗；`backdrop`。
- 真实用法：`backdrop: off`、三个文字变量留空，把这张卡放在高一层的轨道上，下面一层放接下来要讲的内容。小窗落定后（1.4s 以后）可以一直留着，把 `slot` 设成下面那段内容的时长。
- 卡的 0.6 秒对上旁白转话题的那个词（“接下来”“我们换个角度”）。
- 音效：0.6s 一个短的掠过声，1.1s 弹到位时一个轻的弹出声。
- 常和 `title-to-corner` 对着用：一个把画面收到角上，一个把标题收到角上。
