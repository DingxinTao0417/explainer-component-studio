## 命门

1. **光线贴着边缘走，拐角时换边。** 前 0.53 秒光头沿面板左缘从顶边下 620px 爬到角上（竖光），之后沿顶边横走（横光）。横光在 0.36–0.71 秒淡入，竖光到 1.87 秒才淡完，拐角那段两条光叠在一起，读成一条光拐了个弯。只有横光、没有爬左缘的那一段，开场就少了“光从界面边上摸过来”的那一下。
2. **两个匀速、方向相反。** 面板 4.4 秒匀速左滑 1280px（横屏），光头在面板上匀速右移 2960px，合起来光在画面上匀速右移 1680px。任何一个加缓动，光就像自己在找东西，不再是镜头的机械摇动。本卡横屏实测“亮度过半的像素”占画面每 0.33 秒 20.6% → 29.7% → 27.4% → 32.4% → 37.2% → 41.2% → 45.4% → 48.7% → 48.9% → 49.7% → 50.1% → 48.6% → 45.6% → 41.7%，参考片同一时刻 19.4% → 28.3% → 26.0% → 31.0% → 35.9% → 39.8% → 43.9% → 46.9% → 46.7% → 47.4% → 47.7% → 46.8% → 44.1% → 40.2%，曲线同形，整体高 1–2.5 个百分点（面板底色是 `--k-panel`，比原版稍亮）。
3. **光渗进界面。** 光头下方有一片 1240×380 的光晕从顶边渗进界面里（拐角前在左缘有一片竖的），没照到的地方压到 96% 的暗场色。只有边上一条线、界面里没有被照亮的一块，就成了描边动画。

## 已知坑

- 面板比画面宽得多（横屏 3000px、竖屏 2300px），面板层标了 `data-layout-allow-overflow`。
- `src` 截图按面板宽铺满、左上对齐：横屏 3000 宽时 16:9 截图放大 1.56 倍、画面里只露出上面约 55%，1920 宽的截图会发软，用 2 倍图；竖屏 2300 宽时放大 1.2 倍，只铺到面板上部 1294px（画面 y 326–1620），再往下是面板底色，那一带本来就压在暗里。要读的东西放在截图上半部，面板横移时它们才会一一被光扫到。
- 没有落定：4.4 秒还在动。想停在某处就把片段剪短，不要给它加减速（见命门 2）。
- 深色皮下面板也是暗的，光的反差很小，所以深色皮多一层跟着光头走的滤色光池（`--k-on-stage` 14%，只在面板里）；白底皮不加，和原版一样。
- 光层和压暗都是每帧重写的渐变加 blur（最大 30px）：成片用 `render -w 4`。

## 动效与皮的边界

暗场是这张卡的一部分：面板没照到的地方要沉在黑里，顶边以上要是黑檐，光才“照出来”。

属于这张卡的：面板和光头两个匀速、方向相反；光先爬左缘再拐上顶边；辉光线贴着边缘；光晕渗进界面；顶上的黑檐。

只是皮：光的颜色（默认第二强调色；要原版那种紫光，宿主设 `--mc-accent-2: #9652ee`）、面板里的内容和栏数、圆角大小。

和 `glow-wake-panel` 的区别：那张面板斜放、和光同方向漂，有醒有睡；本卡面板正对镜头、反方向横移，像镜头在摇，光一直亮着。

## 接进片子

- 变量：`src` 你的宽界面截图（按面板宽铺满、左上对齐），留空用内置示意看板；`backdrop` 填 `off` 时去掉暗场底和顶上的黑檐，面板仍然盖住顶边以下的整个画面（横屏 86%），所以 `overlay: no`。
- 对旁白：0.53 秒光拐上顶边，0.53–1.37 秒扫过侧栏；横屏光头在 1.92、2.97、4.02 秒依次落在三栏正中，竖屏在 2.27、3.58 秒落在两栏正中。让旁白说每一栏的名字时，光正好在那一栏上面。
- 音效：开头一个长而轻的 `whoosh`，贯穿整段；不要用撞击声。
- 横竖两用：片段写 1920×1080 是横版，1080×1920 是竖版，节奏一样；竖屏面板顶边在 y 326、宽 2300px、两栏各四张卡，面板从 x 200 起滑，拐角那一刻左缘在 x 27。
- 节制：光扫类的卡（本卡、`glow-wake-panel`、`sheen-sweep`）一条片子合计两三次以内。常接在 `glow-wake-panel` 后面串成一段界面巡礼，或者用 `corner-spotlight-reveal` 先把第一块界面照亮。
