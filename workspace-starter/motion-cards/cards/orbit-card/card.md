## 命门

1. **小半圈，一直减速到正面。** 从 −52° 转到 0°，`power2.out`，2 秒。角度超过 70° 开场只看得到一条边；用两头慢的缓动，开场卡片是侧着静止的，像一张摆歪的图，不像镜头已经在走。
2. **高光绑在角度上。** 高光的位置和转角用同一个时钟、同一条缓动，所以它是“因为转了才扫过去”。高光自己另起一个时间匀速扫，读成的是按钮上的流光特效，和镜头没关系。
3. **正对时卡面是干净的。** 高光在转到 0° 之前已经淡完，压暗层也归零。落定画面上还留着一道光或一层灰，观众读图时一直被它挡着。

## 动作拆解

| 时间 | 谁 | 做什么 | 缓动 |
| --- | --- | --- | --- |
| 0.2 → 2.2s | 卡片 | 绕竖轴 −52° → 0°，上仰 7° → 0°，缩放 0.9 → 1 | power2.out |
| 0.2 → 2.2s | 卡面压暗层 | 透明度 0.42 → 0（背光面转向光） | power2.out |
| 0.2 → 2.2s | 高光带 | 从卡片左外侧横移到右外侧（自身宽度的 −110% → 230%） | power2.out |
| 0.2 → 0.6s | 高光带 | 透明度 0 → 0.9 | power1.out |
| 1.3 → 1.9s | 高光带 | 透明度 0.9 → 0 | power1.in |
| 0.2 → 2.2s | 地面投影 | 横向 0.55 倍 → 1 倍，并从偏左 40px 回到正中 | power2.out |

透视距离 1700px。卡片 1160×764，落定时占画面宽的 60%；高光带宽度是卡片的 46%，向左斜 14°。

## 参数手感

| 参数 | 默认 | 调大 | 调小 |
| --- | --- | --- | --- |
| from 起始角度（变量） | −52° | 过 ±70° 开场接近一条线，认不出是什么 | 小于 ±25° 只是歪了一下，没有“绕”的感觉 |
| dur 环绕时长 | 2s | 3 秒更庄重，适合片尾；高光和压暗会自动跟着拉长 | 低于 1.2s 变成翻牌 |
| lift 上仰角 | 7° | 过 15° 像从桌面上拿起来 | 0 时是纯水平环绕，更冷静 |
| far 起始缩放 | 0.9 | 0.8 时带明显的“走近”，接近推镜 | 1.0 时镜头只绕不靠近 |
| shade 侧面压暗 | 0.42 | 过 0.6 开场卡面是黑的 | 0 时没有受光变化，卡片像一张贴图 |
| sheenPeak 高光强度 | 0.9（乘以渐变本身的 42%） | 浅色图上超过 0.6 就发白 | 0 也成立，只是少了材质感 |
| perspective 透视距离 | 1700px | 过 3000px 近大远小消失 | 低于 1000px 近侧的边被拉得很夸张 |

## 已知坑

- 第一版高光是一个矩形里的 100° 斜向渐变，渐变没走完矩形就到边了，结果高光左右两侧是两条直直的硬边，像卡片前面立了一块玻璃板。改成水平渐变（两端正好是 0）再把整个高光带斜切 14°，边才是软的。
- 转动集中在前半段：`power2.out` 下，1.13 秒（过了不到一半时间）卡片已经只剩 15° 左右。连拍的中间帧要靠前取（0.67、1.13 秒），后面的格子看起来都接近正面。
- 卡片用了 `overflow: hidden` 来裁高光，这会把卡片压成一个平面：里面的元素不能再有自己的前后层次，卡片也没有厚度。要做有厚度的卡，得另加一条侧边并换掉裁切方式。
- 高光带扫完后停在卡片右外侧（透明度已经是 0），单独跑检查时被报 `escaped_container`，合跑时没报。包裹层上加了 `data-layout-allow-overflow`；别为了消这条把高光带的终点改回卡片里面，那样落定画面上会留一道光。
- 从右侧绕（`from` 为正）时高光方向会自动反过来，但地面投影偏移是按 40px 写死的，起始角度很大时投影和卡片底边会对不上，可以把偏移调到 60–80px。

## 动效与皮的边界

属于这张卡的：从侧面减速绕到正面、和角度同步的高光、背光到受光的明暗变化、落定时卡面干净。

只是皮：卡片里放什么、有没有标签、卡片的底色圆角描边、高光的颜色和宽度、地面投影的浓淡、底色渐变。

## 接进片子

- 变量：`src` 卡片上的图片地址，`label` 图下的一行字（留空就不显示，卡片自动变矮），`from` 起始角度（负数从左侧绕，正数从右侧），`backdrop` 填 `off` 时只留卡片和投影，可以压在别的画面上。
- 对旁白：卡片在 0.2 秒开始转、2.2 秒正对。把旁白里说出这件东西名字的词放在 1.5–2.2 秒之间，名字说完时它刚好正对观众。
- 音效：0.2 秒起一个 1.5 秒左右、由强到弱的掠过声。
- 连用：正对之后可以接 slow-push 的思路继续缓推；多张卡依次展示时，第二张起把 `from` 的正负号交替。
