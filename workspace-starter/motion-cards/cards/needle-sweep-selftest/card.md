## 命门

1. **先甩满，再回落。** 每根针先用 0.4 秒甩到 270° 的尽头，再弹回自己的读数。直接从 0 走到读数，读起来就是一个普通的进度条，没有“开机先亮量程”的仪式感。去程要起步猛、到头收住（三次方缓出），匀速扫过去像秒针。
2. **回落带一次回摆。** 回程是弹簧，阻尼按“落过头 8°”反算：默认三块表读数 70 / 44 / 87，回程 81° / 151° / 35°，阻尼 13.00 / 14.97 / 9.33。没有过冲就像电子表，过冲两三次又像坏了的仪表。
3. **三块表错开 4 帧，不齐甩。** 第二、三块各晚 0.133 秒，三根针排成一道波浪。齐甩读作复制粘贴；错得太开（0.3 秒以上）三块表就成了三件事。

## 动作拆解

时间是第一块表的（第 i 块整体晚 i × 0.133 秒）；三块表时最后一块 2.2 秒钉死，之后整张卡不再有一个像素变化。

| 时间 | 谁 | 做什么 | 缓动 |
| --- | --- | --- | --- |
| 0 → 0.4s | 整张卡片 | 从下方 18px 升到位，淡入 | snappy |
| 0.267 → 0.6s | 表盘底面、外环、红区、刻度、刻度数字 | 点亮（透明度 0 → 1） | out |
| 0.4 → 0.8s | 指针 | 0° → 270°，扫过的刻度依次变亮，盘面上一条强调色亮弧跟着针长 | power2.out（三次方缓出） |
| 0.8 → 1.6s | 被点亮的刻度 | 亮度退回常态 | smooth |
| 0.8s 起 | 指针 | 弹簧回落：刚度 120、质量 1，阻尼按过冲 8° 反算；读数 70 对应 189°，1.05 秒第一次越过 189°，1.156 秒（第 35 帧）到最低 181°，再回弹到 189.8°，1.61 秒以后一直在 189° ±0.5° 以内 | 弹簧 |
| 指针每帧转过 4° 以上时 | 指针残影 | 身后 4 份淡影（不透明度 0.13 / 0.10 / 0.06 / 0.03） | — |
| 1.467 → 1.767s | 盘下数字 | 缩放 0.4 → 1（冲过头约 8%），0.133 秒内淡入 | overshoot |
| 1.567 → 1.9s | 指标名 | 上移 6px 淡入 | out |
| 1.933s | 指针 | 钉死在读数上 | — |
| 0 → 2.0s / 2.0s 起 | 状态胶囊 | 检测中：强调色圆点按 0.93 秒一个周期呼吸；最后一块表开针后 1.33 秒切成“检测完成”，圆点换第二强调色 | — |

实测原片（三块表读数 70 / 44 / 87，逐帧量针角）：第 13 帧第一根针到 62°、第 24 帧到 270°，和三次方缓出逐帧对得上；三根针分别在第 24、28、32 帧到顶；回程最低点 182° / 112° / 227°，都比读数低 8° 左右；数字在第 45、49、53 帧开始出现。原片是早一版的灰阶占位，回程在顶上多停两三帧，最低点比这张卡晚 2–3 帧（原片 182° 在第 37 帧；这张卡最低 181.0° / 110.8° / 226.9°，第一块在 1.156 秒即第 35 帧）；这里照现行源码的弹簧。原片把读数 70 画在 190°，这张卡按 270° × 70% 画在 189°，所以最低点都低 1° 左右。

## 参数手感

| 参数（脚本顶部） | 默认 | 调大 | 调小 |
| --- | --- | --- | --- |
| CFG.stagger 表间错开 | 0.133s | 过 0.3s 三块表各演各的，看不出是一次自检 | 0 时齐甩，像复制粘贴 |
| CFG.go 去程时长 | 0.4s | 过 0.7s 针是“挪”过去的，没有甩的劲 | 低于 0.25s 一闪而过，看不清扫过了全弧 |
| CFG.over 回摆角度 | 8° | 过 15° 针晃得厉害，像坏了；行程短的表超调比封顶在 0.5；读数的角度比它小时按读数的角度回摆（见已知坑） | 0 时几乎不回摆，像电子表 |
| CFG.stiff 弹簧刚度 | 120 | 200 以上回程很硬很快，和去程分不开 | 60 以下回落拖沓，数字弹出时针还在走 |
| CFG.settle 数字弹出 | 开针后 1.067s | 晚于 1.4s 针停了数字还没来，像卡住 | 早于 0.9s 数字出来时针还在回摆，读数像没定 |
| CFG.calm 刻度回暗 | 0.8s | 过 1.5s 落定后整圈刻度还亮着，抢数字 | 低于 0.3s 亮刻度一闪就没了 |

## 已知坑

- 读数 100 时没有回程（针甩到头就是读数），也就没有回摆；读数 94 以上（回程不到 16°）超调比封顶在 0.5，回摆只有几度，看起来像直接停住。读数小于 0 或大于 100 时按 0、100 画针，数字照写的显示。
- 读数很小时回摆不越过 0 刻度：回摆角度取 8° 和读数角度里小的那个，像表里有一根挡针。读数 0 时几乎不回摆（最低 −0.03°），读数 1、2 时最低正好落在 0°，读数 3 起（8.1°）照常回摆 8°。
- 刻度数字是 28px 的 SVG 文字：亮起时变成墨色，平时是次级灰，不用半透明（半透明的灰字在白底上对比度不到 3:1，检查会报）。换皮时 `--mc-muted` 要在 `--mc-bg` 上够 4.5:1。
- 竖屏每块表一行，卡片 780px 宽，刻度数字只留 0、50、100 三个（半径 118 的表盘放 11 个 28px 的数字会挤在一起）；三行加卡头共 1052px，正好塞进 12%–68% 的安全带，不要再加第四块。
- 指标名放不下时先缩小字号，最小 40px：横屏一格 480px 可用，约 12 个字；竖屏在表盘右边 376px，约 9 个字。再长就换成两行，字号随字数从 40px 降到 32px：横屏最多约 29 个字，整张卡加高 48px；竖屏最多约 22 个字，一行 300px 里正好放下。两行 32px 还放不下时截断，末尾加“…”。卡头标题放不下时换成两行，两行还放不下再缩小，最小 32px。
- 横屏盘下数字的顶在表盘底圈（y 376）下面 8px，不压圈。原版的数字压在表盘底圈上（暗场里底圈几乎看不见），白底上圈线会从数字顶上穿过，所以整组下移了 40px，卡高 680px。
- 指针会盖住它指着的那个刻度数字（读数 70 盖住“70”，44 盖住“40”）。真表也是这样，盘下的大数字已经报了读数，没有改。
- 每根指针（本体、发光、4 份残影）的组里都有一个不画的圆，半径 = 针尖长度 + 4（横屏 151px、竖屏 109px；针尾 34px）。它让组的外框以转轴为中心，verify 才不报 `rotation_pivot_drift`（不加时报 12 条）。改长针身或针尾时，这个圆至少要和针最远的一点一样大。
- 指针的发光和亮弧的柔光是 SVG 高斯模糊，渲染用 `render -w 4`（SPEC「六」）。

## 动效与皮的边界

属于这张卡的：先甩满 270° 再回落的去回程、去程三次方缓出、回程按 8° 过冲反算的弹簧、表间 4 帧的波浪、扫过的刻度依次点亮再回暗、针停稳的同一刻数字带过冲弹出、全部停稳后状态胶囊才切换、落定后指针钉死不漂。

只是皮：卡片的底色和阴影、表盘大小、针的形状和渐变、红区放在最后 1/6（数值 83–100）、刻度数字的疏密、强调色。原版是暗场（深色卡片、琥珀针、红色红区），这张卡按库的规矩改成白底，红区用强调色压暗代替红色；换深色皮时针跟着强调色变成黄色。和 `ring-progress` 的区别是：那张卡只把一个环画到百分比，这张多了“先甩满量程再回落”的自检动作和几块表的错峰。

## 接进片子

- 变量：`values` 读数，0–100，用 `|` 分隔，一到三个，写什么数字就显示什么；`items` 指标名，和读数一一对应；`unit` 读数后面的小单位，默认 `%`，填一个空格就不显示；`title` 卡头标题；`status` 状态胶囊的两句话，`检测中|检测完成` 这样用 `|` 隔开；`backdrop` 填 `off` 时去掉底和暗角，只留卡片，可以压在录屏上。
- 起始时间：第一根针 0.4 秒开甩；旁白说“结果出来了”这类话的那个字放在 0.4 秒。第一个数字 1.467 秒弹出，对上旁白念第一个读数。
- 音效：每根针开甩一声 whoosh（0.4s、0.533s、0.667s）；每块表数字弹出一声 tick（1.467s、1.6s、1.733s）。
- 横竖两用：片段写 `data-width="1920" data-height="1080"` 是横版，三块表并排；写 1080 × 1920 是竖版，三块表竖排成三行，数字在表盘右边，节奏不变。
- 常和 `ring-progress`（只讲一个比例时）、`number-roll`（接着把其中一个数字放大讲）连用。
