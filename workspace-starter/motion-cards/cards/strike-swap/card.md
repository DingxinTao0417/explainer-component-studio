## 命门

1. **先划，后走。** 划线 0.2 秒画完，再停 0.06 秒，旧词才开始下沉。划线和下沉同时发生的话，观众看不清被否定的是哪个词，只看到一团东西在动。
2. **旧词留在画面里。** 它沉到新词正下方，缩到 0.56 倍、透明度 0.45，带着那道线一直待着。直接淡出消失，就成了普通的文字替换，“纠正”的意思丢了。
3. **新词踩着旧词的尾巴进来。** 旧词下沉开始后 0.1 秒新词就出发，两个动作有 0.32 秒重叠，看起来是新词把旧词顶了下去。等旧词完全沉稳再进新词，位置会空一拍，像掉帧。

| --- | --- | --- | --- |
| 开场 0 → 0.35s | 整行（前半句 + 旧词） | 上移 26px 淡入 | power3.out |
| 0 → 0.20s | 划线 | 从左端横向长出，全程倾斜 -4° | power3.inOut |
| 0.26 → 0.68s | 旧词连同划线 | 从行内原位沉到下一行，缩到 0.56 倍，透明度 1 → 0.45，原点在左上角 | power3.inOut |

| 0.36 → 0.76s | 新词 | 从上方 96px 落到行内 | back.out(2.2) |

## 已知坑

- 整行的宽度是按“前半句 + 新词”算的，旧词只是叠在这个位置上。旧词比新词长时，开场那一段整行会偏左、右边多出一截；差两个字以上就改文案，或者把长的那个放在新词。
- 旧词在布局里本来就是下面那行小字，行内的大字状态是靠位移和放大“抬”上去的。所以别给旧词写 CSS 变换，也别改它的 `top: 100%`，否则抬上去的位置对不齐基线。
- `small` 既是 CSS 字号（脚本会写进去），也决定抬升的距离和倍数，三处必须是同一个数；只在样式表里改字号会让旧词开场时大小不对。
- 旧词和新词开场时占同一个位置，HyperFrames 的版式检查会把它当成文字互相遮挡；这是有意的，已经在这两个节点上标了允许遮挡。
- 划线用的是强调色，新词也是强调色。换皮后如果强调色偏暗，划线压在白字上会不明显，可以单独把划线改成正文色。

## 动效与皮的边界

属于这张卡的：划线 → 停顿 → 下沉的先后顺序，旧词缩小变淡但留在画面里，新词从上方进入并且和下沉重叠。

只是皮：划线的颜色粗细和倾角、新词的颜色、旧词停在下方还是上方、字号字重、前半句有多长。

## 接进片子

- 变量：`lead` 不变的前半句；`wrong` 旧说法；`right` 新说法（两者字数尽量接近）；`hit` 划线的秒数，对齐旁白说出“不是”“其实”这类转折词的时刻；`backdrop`。
- 时间：新词在 `hit` + 0.76 秒停稳，旁白说新说法的时间应该落在 `hit` + 0.4 到 0.8 秒之间。
- 音效：`hit` 一个短的划线声；新词落定（`hit` + 0.6 秒左右）一个轻的弹出声。
- 常见接法：前一镜用 `line-rise` 或普通字幕把旧说法完整说一遍，这一镜再纠正；结论性更强、要整句否定时改用 `stamp-verdict`。
