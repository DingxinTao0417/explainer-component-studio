## 命门

1. **由近到远、等间隔地熄灭。** 8 张兄弟卡按离主卡中心的距离排好，最近的 1.0 秒开始灭，之后每隔 0.267 秒灭下一张，读作“世界从中心往外塌暗”。打乱顺序读成画面出故障；一起灭读成硬切。
2. **熄灭、沉黑、光晕都发生在后拉途中。** 镜头 0 → 3.667 秒一路后拉（cubic 缓出，3.09 秒已到终点的 1% 以内）；兄弟卡 1.0–3.4 秒灭完，底色 2.0–3.667 秒沉成暗场，主卡光晕 2.0–3.333 秒亮起。镜头停稳那一刻画面里只剩一张发光的卡。先拉完再灭，读成幻灯片翻页；只沉黑不加光晕，主卡像是跟着一起暗下去了。
3. **先透明，后压暗。** 每张卡 0.533 秒灭完：透明度走 ease-out（走到四分之一时只剩 23%），亮度按进度的平方降到 0.3，同时糊 5px、缩到 0.97 倍。反过来先压暗，亮底上会停着一块块灰板。

## 已知坑

- 落定时主卡很小（横屏 17%、竖屏 35% 画面宽），说明字只有 32px（竖屏 37px），低于正文 40px 的线。这是这个动法本身：卡越小、四周越空越孤立。需要观众读一句话时，在后面接一张压在画面上的字卡，不要把主卡放大。
- 说明超过 7 个汉字开始缩字，到 36px（每行约 11 个汉字）还放不下就折行，这时数字的上限从 150px 降到 104px，否则会压到底下的条带；最多三行（33 个汉字），34 个汉字折成四行时底下的条带被挤没。数字横屏竖屏一样：`99.9%` 150px，`99.95%` 148px，`1,234,567 次` 86px，`12,480 次` 在说明折行时是 104px；最低缩到 72px。
- 暗场用的是 `--k-stage`：深色皮下是从深色底沉到更深的暗场，变化小一些，主要靠兄弟卡熄灭和光晕。`backdrop: off` 时没有亮底和暗场，只剩卡片熄灭和光晕；压在亮画面上光晕几乎看不见。
- 兄弟卡是脚本生成的无字 SVG 面板，只在动作里出现；去掉脚本的静态页就是落定画面（暗场里一张发光的卡），没有兄弟卡是对的。镜头层标了 `data-layout-allow-overflow`：开场时主卡和兄弟卡按设计大于画面。
- 用的是 2D `scale` 而不是原版的 2.2 倍 CSS `zoom` 布局：HyperFrames 截图里 2.2 倍的字照样锐利（开场帧放大看过），代价是 1px 发丝线在开场是 2.2px。8 张卡每帧改模糊和亮度滤镜，成片用 `render -w 4`（SPEC「六」）。

## 动效与皮的边界

属于这张卡的：一直在走的缓出后拉、以主卡为中心；按距离由近到远、等间隔熄灭；熄灭时先透明后压暗再加失焦下沉；底色沉成暗场和主卡光晕同步；最后一段真静止。暗场是这张卡的一部分：结尾必须落在暗处，才有“只剩它”。

和 `pull-reveal` 的区别：那张是从局部特写拉出全貌，再框出刚才看的是哪一块，意思是“原来如此”；这张拉远的同时把周围全部熄灭，意思是“只剩这一个”。

只是皮、可以换的：主卡的内容和样式（数字、说明、条带）、兄弟卡里画什么、光晕的颜色、暗场的颜色（`--mc-stage`）、颗粒。

## 接进片子

- 变量：`value` 主卡数字，末尾的非数字部分（`%`、` 次`、` 倍`）排成 0.56 倍的灰色单位；`label` 数字上方的说明，建议 7 个汉字以内，留空时整行不显示；`backdrop` 填 `off` 时去掉亮底、暗场和颗粒，压在画面上用。
- 起始时间：后拉从第 0 帧就开始、开头最快，所以卡的起点对上旁白收束那句话的第一个词；数字在 3.1 秒左右停稳，旁白说出这个数字最好落在 3–4 秒。
- 音效：开头一个很轻的 `whoosh`（0 秒），熄灭和沉黑不加声音，整张卡靠安静收住。
- 一片只用一次，放在结尾或一段的句号处；后面不要接一下子炸开的收尾（一收一放会打架）。
- 横竖两用：片段写 `data-width="1920" data-height="1080"` 是横版，写 `1080` × `1920` 是竖版；变量和节奏不变，竖屏换了一圈兄弟卡的位置和起止缩放（2.0 → 0.72）。
- 常和 `bullet-time-freeze-orbit` 连用：那张停下来看清数据，这张拉远只留结论数字。
