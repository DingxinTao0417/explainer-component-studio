## 命门

1. **到了先停一拍。** 光标 1.1 秒到位，1.2 秒才按下，中间 0.1 秒不动。滑到就按，观众的眼睛还在追光标，点击那一下就漏看了。
2. **按下快，松开慢。** 按下 0.07 秒，松开 0.28 秒并带回弹。两头一样快像闪了一下，两头一样慢像在按一块海绵。
3. **波纹从按到底的那一帧出发。** 波纹不跟着光标到达，也不跟着松开，而是卡在按钮沉到最低的 1.27 秒。早了像光标自带的光圈，晚了像另一件事。

## 动作拆解

| 时间 | 谁 | 做什么 | 缓动 |
| --- | --- | --- | --- |
| 0.4 → 1.1s | 光标（横向） | 从右方 620px 外滑到点击点（默认位置下起点被夹在 x=1790，实际走 605px） | power3.out |
| 0.4 → 1.1s | 光标（纵向） | 从下方 150px 上移到点击点（默认位置下起点被夹在 y=905，实际走约 100px） | power2.inOut |
| 1.1 → 1.2s | 光标 | 停住 | — |
| 1.2 → 1.27s | 光标 | 以箭头尖为原点缩到 0.84 | power2.in |
| 1.2 → 1.27s | 按钮面 | 下沉 15px，盖住底下的深色垫层；表面提亮 35% | power2.in |
| 1.27 → 1.87s | 第一圈波纹 | 缩放 0.12 → 1（直径 380px），透明度 0.9 → 0 | power2.out |
| 1.39 → 1.99s | 第二圈波纹 | 缩放 0.12 → 1.5，透明度 0.6 → 0 | power2.out |
| 1.36 → 1.64s | 光标、按钮面 | 弹回原位 | back.out(2.2) / back.out(2.6) |

横向先快后慢、纵向两头缓，两条轴不同步，路径就弯了。

## 参数手感

| 参数 | 默认 | 调大 | 调小 |
| --- | --- | --- | --- |
| travel 滑行时长 | 0.7s | 过 1s 像在犹豫 | 低于 0.4s 只看到光标闪到按钮上 |
| settle 到位停顿 | 0.1s | 过 0.3s 像卡住 | 0 时点击被滑行吞掉 |
| sink 下沉 | 15px | 过 24px 按钮像掉下去 | 低于 8px 在视频里看不出 |
| ripple 波纹时长 | 0.6s | 过 0.9s 波纹还在散，下一句旁白已经开始 | 低于 0.35s 像闪光 |
| aimX / aimY 落点偏移 | 225 / 28px | — | 0 时箭头正好压在按钮文字上 |
| click（变量）按下时刻 | 1.2s | — | 小于 1.0s 会被抬到 1.0（滑行加停顿至少要这么久） |

## 已知坑

- 第一版把点击点放在按钮正中，落定后箭头把“开始导出”四个字盖住了一半。现在点击点在按钮中心右侧 225px、下方 28px（按钮 700×170px、字 70px，箭头整个还在按钮右半边里）；按钮比 600px 窄时把 `aimX` 改小。
- 波纹的起始透明度不是 0。如果只写一条从 0.9 到 0 的补间，时间轴停在点击之前时波纹圈会一直亮着。现在是“0 → 亮 → 0”三段，点击前恒为 0。
- 光标起点太靠下会被画面底边切掉一截：箭头是 120×165px，第一版起点在点击点下方 250px，连拍第一帧只露出半个箭头。现在是下方 150px，并且把起点夹在画面内（x 不超过 1790，y 不超过 905）；点击点越靠下，纵向的弧度越小，y 超过 850 时路径接近水平。
- 光标压在按钮文字上会被校验当成遮挡，在按钮和文字上加了 `data-layout-allow-occlusion`。
- 浅色按钮配白色波纹看不见：波纹用的是 `--k-ink`。换成浅色皮时把波纹改成深色或强调色。
- 示例面板是 1580×900（画面宽的 82%），默认点击点 (1185, 803) 时正好居中。`x / y` 改了面板会整块跟着挪，偏离默认值超过 170px（横向）或 90px（纵向）面板就出画；那种位置请用透明模式压在真实画面上。
- 透明模式下没有按钮可以下沉，只剩光标和波纹，点击感弱一半。可以把 `sink` 的位移加在录屏层上做一次 5px 的轻推作为补偿。

## 动效与皮的边界

属于这张卡的：两轴不同步的弧线、到位后的一拍停顿、快按慢放、波纹卡在按到底那一帧、按钮面和垫层的相对位移。

只是皮：光标造型和大小，按钮的颜色、圆角、文字，周围的示例面板，波纹是一圈还是两圈。

## 接进片子

- 变量：`label` 按钮上的字；`x / y` 点击点（画面像素，示例面板会自动挪到让按钮落在点击点左上）；`click` 按下的时刻；`backdrop` 填 `off` 时只留光标和波纹，压在真实录屏上。
- `click` 对齐旁白里的动词（“点”“按”）。真实录屏里按钮有反应的那一帧也对在 `click + 0.07` 秒。
- 音效：`click + 0.07` 秒（默认 1.27 秒）一个短促的弹出声或鼠标声。
- 接法：前面用 `spotlight-dim` 或 `screen-push-focus` 把按钮所在区域指出来；点完之后切到结果画面。
