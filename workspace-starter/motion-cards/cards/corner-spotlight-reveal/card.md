## 命门

1. **扩张严格匀速。** 光圈半径在 0–3.33 秒线性长大，不加任何缓动。本卡横屏实测“亮度过半的像素”占画面每 0.33 秒是 2.7% → 13.0% → 30.1% → 50.4% → 68.1% → 84.5% → 94.6%，参考片同一时刻是 2.8% → 13.6% → 31.1% → 50.9% → 68.8% → 85.1% → 96.4%，逐格差不到 2 个百分点。换成 out 类缓动，前 1 秒就亮了大半，读成“有人把灯打开了”，不再是探照灯机械地扫开。
2. **半径终值刚好在 3.33 秒盖满画面。** 终值按“最远的画面角在 3.33 秒刚被照到”算：横屏 1300 页面 px，竖屏按自己的远角算出 1248。本卡 3.33 秒时横屏右下角 (1900,1060) 的亮度是 236，页面底色 244，到了 97%；竖屏右下角同样是 236。终值调大，光在前半段就饱和，后半段画面不动，看起来就不匀速了（终值改成 2600 实测：1.33 秒已照亮 95% 的画面，1.67 秒右下角也到 95%）。
3. **光外是实打实的黑。** 光圈以外是 `--k-stage` 实色，光圈边从 0.79 倍半径到 1.85 倍半径线性羽化。用半透明压暗代替黑，界面一开始就隐约可见，没有“照到 / 照不到”的界线，转场的意思就没了。

## 动作拆解

半径和光心都在页面自己的坐标（页面 px，镜头放大之前）。

| 时间 | 谁 | 做什么 | 缓动 |
| --- | --- | --- | --- |
| 0 → 3.33s | 光圈半径 | 160 → 1300（竖屏 → 1248）；实心到 0.79 倍，外沿 1.85 倍 | none |
| 0 → 3.2s | 光心 | 横屏 140,90 → 420,260；竖屏 79,160 → 236,462（都是画面宽高的 7.3%、8.3% → 21.9%、24.1%） | none |
| 0 → 4.33s | 镜头 | 绕页面 18%、12% 处：缩放 1.75 → 1.47（3.33s）→ 1.386，平移 −40,−30 → 30,20 → 51,35 px，旋转 −1.2° → 0° → 0.36°；3.33 秒后照样漂，不停 | none |

## 已知坑

- 光外的黑是一层盖在界面上的 `--k-stage` 幕（开口跟着光走），光晕也压在界面上，所以标题的每个字块、五个标签都标了 `data-layout-allow-occlusion`：检查会把被幕压暗的字当成被遮挡、对比度不够。换文案后照样要看连拍：1.33 秒以后标题和标签都在亮处。
- 页面比画面大，镜头一直在动：相机层标了 `data-layout-allow-overflow`。字的位置按 1.33 秒（`hero`，缩放 1.638）算过两个方向的安全区：在那之前竖屏镜头更近，标题会碰到上边 12% 和左边 10%，所以 `hero` 不能再往前挪；改了镜头的起止要重量一遍。
- `src` 截图铺满画面、左上对齐，再被镜头放大 1.39–1.75 倍：1920 宽的截图会发软，用 2 倍图（3840×2160）。竖屏铺满时 16:9 截图要放大到 1920 高（3413 宽），横向只露出左边 1080，约三分之一。
- `backdrop: off` 时去掉界面，只留暗幕和光晕，开口里露出宿主的下一镜。暗幕是 `--k-stage`，压在很暗的下一镜上光圈边几乎看不见，这时用 `iris-close` 之类带亮边的转场更好。
- 暗幕的渐变和 26px 的光晕每帧都在变：成片用 `render -w 4`。

## 动效与皮的边界

暗场是这张卡的一部分：光是“照出来”，去掉黑就只剩一张界面截图。

属于这张卡的：从左上角起、严格匀速、终值刚好在片尾盖满、羽化 0.85 倍半径、镜头同时缓缓拉远而且不停、光晕先亮后灭。

只是皮：界面内容（内置示意页或截图）、光晕颜色（`--k-on-stage`）、暗场颜色（`--k-stage`）、标题文案、标签。

和 `iris-close` 的区别：那张是收和开一对、用缓动、圆心固定、约 0.63 秒完成的硬转场；本卡只张不收、严格匀速、3.3 秒的慢显影，还带镜头拉远和光晕。和 `spotlight-dim` 的区别：那张把已经亮着的界面压暗、收成亮窗去指某处；本卡是从全黑把整个界面照出来。

## 接进片子

- 变量：`title` 内置示意页的标题，用 `|` 切意群，可以填空字符串（标题行整行去掉，标签上移）；`src` 你的界面截图，填了就不画示意页；`backdrop` 填 `off` 时只留暗幕和光，压在下一镜上当转场。
- 长度：横屏标题一行，118px 时约 7 个汉字（6 个字的 `自动整理一下` 实测 118px，右边到 x 1249），缩到下限 72px 时一行约 12 个，再长折成两行（`第3节|把整个流程完整地跑通一遍` 实测 72px 两行，右边到 x 1630）；竖屏 118px 时一行只有 3 个汉字，4 个字缩到 108px，72px 时一行 6 个，再长折行：23 个字五行（1.33 秒 y 247–964），标签随之下移到 y 1101–1238，仍在 1306 以上。标签是固定文案，横屏五个、竖屏三个。
- 对旁白：1.0 秒照亮一半画面，2.0 秒照亮 95%；让下一节的第一句话落在 1–2 秒之间。
- 音效：0 秒起垫一个 3 秒左右的上扬（`rise`），在 3.3 秒前收住；不垫也成立。
- 横竖两用：片段写 1920×1080 是横版，1080×1920 是竖版，节奏一样；竖屏页面重排（标题、三个标签、六行），光心和半径终值按竖屏画面算。
- 常连用：前面接 `iris-close` 收黑，或者放在全片第一镜；照亮之后接 `spotlight-dim` 指界面里的某一处。
