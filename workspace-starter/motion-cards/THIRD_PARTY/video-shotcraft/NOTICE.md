# video-shotcraft 移植说明 / Porting notice

## 中文

### 来源

- 项目：video-shotcraft，github.com/Vincentwei1021/video-shotcraft
- 依据的版本：提交 `43bd349`（2026-10-18）

- 原项目没有 NOTICE 文件，所以这里没有需要转载的 NOTICE 内容。

### 拿了什么

- **动法配方**：`references/shots/<分类>/<配方>.md` 里的镜头配方，和 `demos/<分类>/<配方>/<镜头>.tsx` 里调好的时间、缓动曲线、编排和常数。每张移植卡只取其中一个动法（一个配方有几式时，各式分成几张卡，只是换皮的几式并成一张卡的枚举变量）。
- **共用工具的做法**：`demos/_fixtures/` 里 Polish、Look、Motion、PageCam2D、Fixtures 的思路，重写成卡里可以直接粘贴的小段代码（缓动预设、颗粒、暗角、两层软阴影、发丝线、按速度的方向模糊、舞台布光、逐字逐词揭示、2.5D 页面相机、无字的假界面）。部分公式和常数沿用原值，例如 8 条贝塞尔缓动、颗粒滤镜的参数、软阴影公式、页面相机的坐标数学。

### 改了什么

- 从 Remotion / React 组件改写成 HyperFrames 子合成：一个单文件 `demo.html`，用本库自己的 MT 引擎（`lib/mt.js`），时间从帧（30 fps）换成秒。
- 外观换成本库的中性规格：`--k-*` 色板（默认白底，一个强调色），需要暗场的卡用可换皮的 `--k-stage`；字体换成系统字体栈；示例文案换成中性的中文教程内容。
- 去掉了全部品牌内容：原项目的标志（镜刻 / Frame Chisel）、字标、品牌色、宣传语（PITCH）和项目名，换成通用的内联 SVG 示意标志和泛指文案。
- 真实页面截图换成本库的示例图（`lib/samples/`）或卡内用 HTML / SVG 画的无品牌假界面。
- 没有带进来：`assets/audio`（Mixkit 等各自的许可）、`demos/_textures` 截图、赞助商标志、画廊视频和 README 里的图片、Remotion 本身的代码。
- 每张卡另写了本库格式的说明 `card.md`（命门、动作拆解、参数手感、已知坑等），是重新写的，不是翻译。

### 每张卡怎么标

- `card.md` 前言写 `source: video-shotcraft/<分类>/<配方文件名>`。
- `demo.html` 的 `<template>` 开头有一段注释：原文件路径、许可、版权和这张卡的具体改动。`node tools/cards.mjs lint` 会检查这两处。

### 许可状态和商标

- 带 `source: video-shotcraft/…` 的卡（`demo.html` 和 `card.md`）是 Apache-2.0 作品的衍生作品，按 Apache-2.0 分发，分发时带上本目录。库里其他文件不受影响。`use` 和 `site` 会把 `THIRD_PARTY/` 一起复制。
- video-shotcraft 这个名字只用来说明来源。本库和原作者没有关联，也不代表原作者认可本库。原项目的名字、标志和品牌元素不出现在任何卡的画面、文案、类名或 id 里。
- 原项目的部分配方本身参考过公开作品的手法（见原项目 `references/shots/ATTRIBUTION.md`），原项目声明那些都是重新实现、没有原素材。移植这类配方时，在下表“上游手法参考”一栏照抄它记的来源，不引入那些作品的任何品牌元素。

## English

### Source

- Project: video-shotcraft, github.com/Vincentwei1021/video-shotcraft
- Version used: commit `43bd349` (2026-10-18)
- Licence: Apache License 2.0; the full text is in `LICENSE` in this folder, copied verbatim.
- Copyright 2026 Wei Yihao
- The upstream project ships no NOTICE file, so there is no NOTICE text to carry forward.

### What was taken

- **Motion recipes**: the shot recipes in `references/shots/<category>/<recipe>.md` and the tuned timings, easing curves, choreography and constants in `demos/<category>/<recipe>/<Shot>.tsx`. Each ported card takes one motion; a recipe with several styles becomes several cards, and styles that differ only in skin become one card with an enum variable.
- **Shared helpers**: the ideas behind `demos/_fixtures/` (Polish, Look, Motion, PageCam2D, Fixtures), re-implemented as small copy-in snippets. Some formulas and constants are kept as they were: the eight bezier easing presets, the grain filter parameters, the soft-shadow formula and the page-camera maths.

### What changed

- Rewritten from Remotion/React components into single-file HyperFrames sub-compositions (`demo.html`) driven by this library's own MT engine (`lib/mt.js`); frames at 30 fps became seconds.
- Restyled to this library's neutral spec: the `--k-*` palette (white by default, one accent), a skinnable `--k-stage` for effects that need darkness, system font stacks, and generic Chinese tutorial copy.
- All branding removed: the upstream mark (镜刻 / Frame Chisel), wordmark, brand colours, PITCH taglines and project name are replaced by a generic inline-SVG mark and generic copy.
- Live page screenshots replaced by this library's sample images (`lib/samples/`) or brand-free fake UI drawn in HTML/SVG inside the card.
- Not taken: `assets/audio` (Mixkit and other licences), the `demos/_textures` screenshots, sponsor logos, gallery videos and README media, and Remotion's own code.
- Every card has a new `card.md` written in this library's format; it is newly written, not a translation.

### How each card is marked

- `card.md` front matter: `source: video-shotcraft/<category>/<recipe-file-stem>`.
- `demo.html`: an HTML comment at the top of the `<template>` naming the source file path, the licence, the copyright and the changes made to that card. `node tools/cards.mjs lint` checks both.

- The name video-shotcraft is used only to state where the work came from. This library is not affiliated with or endorsed by the upstream author. The upstream name, mark and brand elements appear in no card's visuals, copy, class names or ids.
