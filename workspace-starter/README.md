# 工作区起步模板

`science-video-director` 把品牌包、手法库和每期项目放在同一个目录里，叫“工作区”。这个文件夹是工作区的空骨架：目录和说明都在，内容要你自己准备。

作者自己的品牌包和手法库没有随仓库发布。品牌包是频道的长相和声音，手法库是从作者喜欢的视频里拆出来的，都得换成你自己的才有意义。

怎么一步一步填满它，见仓库根目录的 [工作区初始化指引](../WORKSPACE_SETUP.md)。

```
workspace-starter/
  brand-kit/        品牌包占位：要做哪些文件、每个文件给谁用（见里面的 README）
  手法库/           手法卡的索引、模板和一张示例卡
  待拆解视频/       你喜欢的参考视频放这里
  已拆解视频/       拆完的参考片移到这里，看片时拿来并排比
  频道复盘.md       每期发布数据一行
```

`projects/`（每期项目）由 `scripts/init-workspace.py` 在你的工作区里新建。
