# Txxx 名称（4–10 字，说清“做什么”）
- 标签：钩子 / 主持人 / 证据 / 结构 / 比喻情境 / 文字 / 转场 / 节奏 / 声音（选 1–3 个）
- 来源：（简称 + 时间点，写到秒；多个来源用分号隔开。没在任何片子里看到的，写“通用做法（未在参考片中观察）”。自己某期用过且认可，在行末加“已用于：<期名> <镜头号>”）

## 看到了什么
只写真的看到的：画面里有哪些元素、什么颜色、字大约占画面多高、停了几秒。估计的数字标“目测”。

## 为什么有效
一两句：它替观众解决了什么。

## 在本频道怎么用
- （举一个你频道里的具体镜头）

## 怎么做
- 组件：用哪个品牌组件、填哪些变量、选哪套调性。
- 动效：照哪个 HyperFrames blueprint id / rule id 做（只写真实存在的 id）。
- 素材：需要什么录屏、截图、生图、口播。
- 数字：字号、占画面比例、入场时长。

## 别这样用
容易用错的地方。

## 节奏参数
每次停多久、多久用一次、一期最多几次。
