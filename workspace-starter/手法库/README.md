# 手法库

从你喜欢的视频里拆出来、可以直接照着做的镜头手法。一张卡一个手法，写清楚：看到了什么、为什么有效、在你的频道怎么用、用哪个组件怎么做、别怎么用、停多久。

它不是规则。skill 的画面标准（`guide/visual-grammar.md`）管“做到什么程度”，手法库管“具体用什么招”。两边冲突时以 skill 为准。

这是起步模板，只带一张示例卡。skill 的指南里提到的“30 张手法卡”和具体卡号是作者自己库里的，不在这里；你的卡从 T001 排起（示例卡占了 T001，可以改写或接着排 T002）。

```
手法库/
  README.md                    本文件
  INDEX.md                     全部卡片总表 + “想做什么 → 先看哪几张卡”
  cards/Txxx_短名.md           手法卡，一张一个手法
  templates/technique-card.md  写新卡用的模板
  拆解/<名字>/DISSECT.md       每条参考片的拆解
```

## 怎么长大

每找到一条喜欢的视频，走一遍：

1. 把视频放进 `<工作区>/待拆解视频/`。
2. 运行 `python -X utf8 <skills目录>/science-video-director/scripts/dissect.py <视频路径>`。它在 `拆解/<名字>/` 写出 `DISSECT.md`，带接触表、开头逐秒图和节奏统计。
3. 看接触表和逐秒图，在 `DISSECT.md` 里补上逐时间点的观察：时间、画面、属于哪类（主持人 / 证据 / 结构 / 比喻）。
4. 写卡。先查 `INDEX.md`：已有同类手法的，把新来源（带时间点）加进旧卡；用法明显不同的才复制 `templates/technique-card.md` 开新卡，编号接着最大号往下排。
5. 更新 `INDEX.md` 的两张表。
6. 把视频移到 `<工作区>/已拆解视频/`。

写卡的规矩：

- “看到了什么”只写看到的，估计的数字标“目测”。
- 正文控制在约 350 个汉字，剪辑师看了就能做。
- 卡不删除。用下来不好的，在 `INDEX.md` 名称后标“（停用：原因）”，编号不复用。
- 参考片的截图和接触表是别人的画面，留在本地，不要提交到公开仓库。

## 做片时怎么用

1. 写导演阐述之前打开 `INDEX.md`，按本期要解决的问题查“想做什么 → 先看哪几张卡”。
2. 在 `planning/BRIEF.md` 里点名 2–3 张卡作为本期的招牌手法。
3. 排分镜时，用到某张卡的镜头写上卡号。
4. 做完且认可的，在卡的“来源”行末尾加“已用于：<期名> <镜头号>”。同一个手法在两期以上用过，或在两条以上参考片里出现，再考虑写进 skill 的标准。
