# 镜头分层、画面密度与动态复查

用于把用户确认的组件样板落实到本期画面。通用分层方法与本用户的外观偏好分开：具体外观见 [本机预设](local-pipeline.md)，本期 design 与用户最新修正优先。不要把一次“取消钩子”变成以后都不用钩子，也不要把某镜的放大比例套给所有窗口。

## 五层分别选择

逐镜分别决定：常驻背景、装饰外框、内容主体、字幕、转场。主体自己的窗口边框属于内容层，不等于外围课件框；关掉外框不能顺带关掉背景或字幕。软件、动画、实拍互切时也保留各层各自的策略。

本用户以 Pexels 真实图片、自己的录屏、提供或按交接要求制作的视频混剪为默认方向。下表的库外观是可沿用的偏好，服从本期按“风格 → 背景 → 外框”取得的选择；“常驻背景”仅在适用镜头使用，不代表每段全屏媒体都必须露出库背景。图片、录屏和视频可作主体，组件可独立承担图解，也可只叠加必要标注。

| 镜头类型 | 主体与装饰外框 | 背景与字幕 |
| --- | --- | --- |
| 动画讲解、关系图、课件 | 使用本期确认的讲解外框，内部组件保持同一视觉系列 | 使用已选常驻背景，字幕在独立安全区 |
| 软件界面演示 | 保留软件自身窗口；按本用户偏好去掉外围白色课件板、虚线框与圆形角饰 | 透视网格仍在窗口后滚动，窗口之外能看见背景；字幕保留 |
| 实拍素材 | 尊重素材构图，本用户默认不套讲解外框 | 可直接铺画幅，字幕和必要标注独立叠加；不强求露出网格 |
| 极简主题卡 | 主卡只放约定的主题文字，使用用户指定的边框 | 标题精简不等于隐藏口播字幕；是否隐藏须有明确要求 |

用户圈出组件的一部分时，查看实际样板并识别它对应的层和组件，不能只凭“圆角框”等名字找近似替代。参考图上的红色批注框不是成片装饰。批准的预览图需落实为实际比例、边距、线型、角饰、字号与层次；只有颜色相同不算复现。

## 主体比例与品牌

- 先在最终观看尺寸下检查主体是否读得清。软件窗口可等比放大，留出背景边缘和字幕安全区；仍有小字时推近相关操作区或调整可编辑字号，不拉伸 UI，也不把整个界面缩成大卡片中的小缩略图。
- 区分有意留白的主题卡与信息主体过小的讲解镜头。后者优先放大关键对象、拉开主次、补足有含义的对照或连接；不靠更多装饰、重复旁白或无关文字填空。
- 明确展示豆包、豆包工作或 Codex 身份的窗口、品牌卡，应使用对应的真实 Logo/头像资产配合名称。先查库图标和现有本地素材，保持原比例与透明边缘，不能用 AI 重画；普通豆包与豆包工作不得混淆。忠实复刻的 UI 若原处没有标记，可另作讲解标识，不伪称为原生控件；仅字幕提到产品不要求额外贴标。

## 背景与动作的连续性

- 用户选择“透视网格滚动”时必须实际运动，不能以一张静态网格图替代。背景由全片时间驱动，连续镜头不从零重启；前景窗口与课件保持稳定。移除某镜的装饰外框后，再检查网格仍可见且继续滚动。
- 对表达推导关系的动画，先建立对象或步骤，再让连线逐渐到达目标，随后揭示结论。不要同时提前亮出终点答案；旧状态要完整退出，避免表格两组文字叠在一起。
- 增加切镜和动效时，围绕信息变化安排，每个重点动作选择对应音效及落点；背景滚动不加连续提示音，不以效果数量作为丰富度。
- 全屏遮挡转场放在画布级，覆盖整个输出画幅，不受内容卡的内边距、缩放或裁切容器限制。查看上下左右边缘及遮满时刻，防止背景或旧内容从留白带露出。

## 实际合成后的复查

沿用 [后期验收](postproduction.md) 与现有审片记录，不另建批准环节。检查本期合成画面，不只看单个组件的库预览：

1. 代表静帧核对本镜外框例外、真实 Logo、主体比例、字幕，检查细小孤立圆点、悬空线头、重影和裁切；先以可读尺寸看细节，再看实际预览尺度的整体。
2. 顺播关键动作与转场的前、中、后，检查因果顺序、背景连续和全画幅覆盖；正常播放与跳到同一时点的可见状态应一致。
3. 对分步揭示、绘制连线、状态切换，补看后段向前拖动、跨镜头回拖和重播。不能只验终态截图；结论抢先出现、步骤回拖后消失都要修复。
4. 局部修改复查受影响镜头、依赖它的图层和相邻转场；声音或时长变化另核字幕与声效。已有未变内容不反复重做，全片通过结论仍绑定当前版本。
