# 组件模板与本期内容分离

本用户要求组件库保持可替换、与具体视频主题无关的模板。复用组件制作视频，以及明确受托整理组件库时，按以下边界执行。

## 适用范围

覆盖库内全部类别：软件界面（含豆包、Codex）、开发与数据、系统与设备、讲解图形、B-roll、动画风场景及基础部件。以当前 manifest 和源码清单为准，不用历史数量限定范围，也不因部分组件是界面复刻就跳过其业务内容。

制作某一期视频时，把采用组件的内容放在本期独立配置中；维护共享组件默认值只在用户授权的库维护范围内进行。仅要求更新 skill 或先讨论方案时，不修改组件库、生成视频或发布网站。

## 模板保留什么，内容替换什么

- 保留布局、图形、行列结构、连接关系、样式、动效、交互状态及必要的品牌和功能标识。播放、下载、搜索等库操作文案，以及界面真实存在的发送、停止等功能名称不当成案例文案清空。
- 将具体主题、结论、人物、组织、聊天与提示词、文件名、地址、文档正文、命令日志、代码、表格字段与数据、图表名称及标注文案改成对应槽位的通用示例。包括写在绘制函数、SVG、动画回调或回退值里的固定内容。
- 占位内容表达用途，例如“主标题”“副标题”“正文内容”“用户消息”“回复内容”“字段名称”“项目 A”“示例文件.txt”；按原有层级和密度提供合适的长短与多行内容，不把所有文字删空或重复成同一个词。
- 数值、日期、代码和状态保持有效的数据类型与结构。代码用不绑定本期题材的合法示例；图表、合计和状态展示与示例数据一致。保留必要的状态区分，不因改名破坏筛选、排序或状态切换。
- 将业务内容暴露为可编辑参数；渲染和动画依据稳定的 ID、角色或状态驱动，不依赖某一句中文或旧案例数值。复刻界面中的业务字段、消息和结果同样可以替换。
- 原始参考图、实录与素材来源作为依据保留。含固定案例文字的截图不能冒充已经模板化的可编辑组件；区分参考展示与实际组件预览。

## 全库整理时的覆盖与验收

1. 从 manifest 与源码建立逐组件清单，检查默认配置、嵌套参数、回退内容、固定绘制文字及内容驱动的动画。包括动画所引用的组件、默认下一场景和组合示例。
2. 先用表格、聊天、文档、连线图解等能代表差异的组件核对模板语义、长短与多行排版；沿用已确认风格后覆盖其余类别。用户已确认方向时不重复设置批准闸门。
3. 同步更新默认内容、公开组合示例、动画演示、生成的预览与缩略图，检查列表、详情、独立示例和导出配置使用一致的模板内容。历史视频工程与原始参考材料不在批量替换范围内。
4. 用替换后的内容实际预览，检查文字可读性、溢出、遮挡、空白，以及输入→结果、节点→连线→后续节点等先后关系；拖动时间轴核对状态。文字替换不能让动画目标失效。
5. 汇报实际处理的类别、数量、遗漏及验证结果；只改默认 JSON 或重新构建成功不足以宣称全库完成。Git 提交、推送与网站部署沿用本次授权边界，不因模板整理自动执行。

## 用于具体视频

在本期场景配置中填入与稿件、声音和事实依据一致的内容，再进行排版和时间对齐。库中的占位文字只用于识别组件结构，不能直接带入交付视频。

视觉审查同时排除模板占位、旧期案例文案、示例聊天、日志和不相干数据残留；包括转场后出现的下一场景及隐藏后再显示的状态。标明案例演示的业务内容应来自本期设计，不能将作者填入的模拟结果描述为真实执行证据。
