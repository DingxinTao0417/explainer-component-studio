# 素材检索与生成

## 先查已有，再按素材职责选路线

每个缺口先确定内容必须证明什么、画幅、画面主体、清晰度和预计时长。纯概念或精确关系也可直接用可控图形，不强行为它寻找照片。

1. 检查本期用户材料和本地可复用素材库，来源与使用条件仍需跟随素材。
2. 通用实拍照片或视频优先通过 Pexels API 获取，按 [Pexels 与 image2 素材](pexels-image2-assets.md) 搜索、查看候选、选文件并下载到本期。具体事件、产品操作或科学证据另找官方/原始来源；Pexels 场景素材不能冒充当事现场。Pexels 候选不适用或接口不可用时明确原因，再考虑 Wikimedia Commons、公共机构开放图库等适用来源。
3. 保留具体素材页、作者、许可依据、署名、下载日期和源片采用区间。Pexels 按其实际许可与 API 使用要求登记为免费授权素材，不标为 CC0 或开源；其他候选各自核对条件。搜索结果缩略图、无水印或可下载均不是许可依据。
4. 需要定制透明主体、装饰物、材质或特殊背景时，选择 image2 生图/编辑路线，先按 [风格参考与能力分支](design-and-generation.md) 取得用户风格参考并检查实际工具；有能力按当前 `imagegen` 执行，无能力交详细生图提示词等图片回传。前景输出真实 alpha 并分层合成；背景按内容设计留白、纵深和运动余量，同环境多镜先单独准备 ENV 图。图库无合适实拍时也可生成明确标示的示意素材，不能替代必须真实的证据；不为漂亮而塞入无关 B-roll。精确文字、Logo 和数据优先使用现有图标/组件及后期排版。
5. 静态图加推近、平移、圈注足以讲清时留在 HyperFrames。需要主体结构变化、物理动作或无法拍摄的连续过程时，先按 [用户生成视频素材交接](user-video-handoff.md) 判断执行方式：本用户默认由助手完成参考图流程与逐镜详细提示词，再等待用户生成视频；实际图缺失时先等待图片，不能跳过核对。仅明确采用 Agent 自动生成且目标为 H3 时，才把经核对的参考图交 H3 执行。

媒体处理按可用 `media-use` 的采用/记账流程接入；不能把其默认图库或生成后端替代用户选定的 Pexels API / image2 路线。所有最终依赖冻结为本地文件，预览与渲染不临时联网取素材。

## H3 镜头包

本节仅适用于目标平台为 H3 的镜头。用户交接模式可借用 H3 的提示词规范，但不运行工作流；其他平台采用其实际支持的格式，不套用六字段、帧网格或 Budget 设置。Agent 实际执行前读 `h3-science-video` 及其提示词规范，并核对 `ai_video_mode` 与已有授权。每镜记录：

- `shot_id`、对应配音区间、一个理解目标、事实/示意/类比性质。
- 已查看的参考图、职责和实际节点绑定；初态、单一主动作、终态与不可变约束。
- 英文六字段提示词，中文场景文字如需出现则保留原文；字幕、精确标签由后期完成。
- 工作流快照、当前模型/节点、seed、生效参数、期望长度与生成后真实帧数/时长。
- 运行授权依据、次数/预算限额、已提交次数、任务 ID、候选路径与入选/返修原因。

默认 `overall_soundscape` 要求无旁白、无音乐，`non_diegetic_music: N/A`；整期配音/BGM/SFX 在 HyperFrames 单独混合。模型是否实际关闭音频计算必须看节点，提示词静音不是后端能力保证。

先做有代表性的一个镜头并动态核对。按已有授权继续；不能将“生成整期”的要求解释成无限次数的收费返修。新运行前查已经提交的任务，失败或状态不明时停止该镜重复提交，继续可做的剪辑与素材准备。

人工审片检查讲解事实、数量/方向/初终态、主体变形、参考偏离、运动和最终裁切。需要严格数字或轨迹而 H3 不稳定时改为 HyperFrames 图解。超分不能弥补事实错误和丢失结构。

## 台账与署名

所有采用素材进入 `ASSETS.json`，候选也可保留但 `selected: false`。未知许可保持 pending，不进入最终素材就绪状态。`ATTRIBUTION.md` 按最终采用素材整理署名、原始链接、许可链接和修改说明，包括 BGM 与音效。用户材料记录“用户提供”与必要的来源说明；不把台账字段当法律结论。
