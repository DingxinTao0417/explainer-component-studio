# 请外人看片：派给子代理的提示词模板

把 `{…}` 换成本期内容后，整段发给一个**新开的**子代理。做法上有三条，都是为了让它真的是“外人”：

- 不要把你自己的结论、自查表、“我觉得没问题的地方”发给它。只给下面列的材料。带着你的结论去看的人，多半会把你的结论再说一遍。
- 改完以后想再看一轮，另开一个新的子代理，不要让同一个接着看：看过上一版的人会不自觉地替上一版辩护。
- 镜头超过 8 个接触表（约 4 分钟以上）时，拆给两个子代理各看一半，再请其中一个额外连着看全片的版式轮换。

这是加分项，不是必过的关卡。它挑出来的问题由你判断改不改；拿不到它的回报，就如实告诉用户“这一版没有请外人看过”，不要自己看一遍冒充。

---

你要以第一次看到这条视频的观众身份，替一条中文 AI 教程视频挑毛病。你没参与制作，也不需要客气。你看不到视频本身，看的是从视频里抽出来的图。

**先读（按顺序）：**

1. `<skills目录>/science-video-director/guide/visual-grammar.md`：这个频道的画面标准，重点看第 3、4、5、7、10 节；
2. `{项目}/planning/BRIEF.md`：这期想让观众明白什么、想给什么感觉。

**再看这些图（都要打开看，不要只读文件名）：**

- 开头逐秒：`{qa目录}/hook_01.jpg`
- 全片接触表（每 2 秒一格，左上角是时间）：`{qa目录}/sheet_01.jpg` … `sheet_{NN}.jpg`
- 卡词帧（每行左边是某个词说出口之前，右边是说出口之后；编号对应的词在 `{qa目录}/REPORT.md` 的“卡词帧”表里）：`{qa目录}/cues_01.jpg` …
- 和参考片的并排对比（左边本片，右边用户喜欢的参考片）：`{qa目录}/compare_01.jpg` …（没有就跳过）
- 声音你听不到，看这两份报告代替：`{音频报告目录}/REPORT.md`、`{音效报告目录}/SFX.md`（没有就跳过）

需要看清某一处时，可以单独抽帧放大：`npx --yes hyperframes@0.8.57 snapshot --at <秒> --zoom <x,y,w,h>`（在 `{项目}/hyperframes` 目录下运行）。除此之外不要改任何文件、不要渲染、不要发布。

**按这几项挑，每个问题都要写时间点：**

| 看什么 | 要问的问题 |
| --- | --- |
| 开头 | 前 3 秒知道这条视频要给我什么吗？第一帧是结果、反差或问题，还是标题卡？ |
| 看得清 | 接触表每一格里的字、标签、字幕都认得出吗？哪一格主体太小？ |
| 看得懂 | 卡词帧右边那一格，画面是在回应刚说的词吗？左边有没有提前剧透？框和箭头套住目标了吗？ |
| 不乱 | 哪一格同时有三组以上的东西、四角全占满、两个大字抢戏、文字贴边或叠在一起？ |
| 不单调 | 连着看相邻几行，有没有“又是这个版式”的感觉？哪一段超过 20 秒都是同一类画面？ |
| 有人味 | 人（真人、角色、头像）在开头、换章、结尾出现了吗？哪一大段完全没有人？ |
| 可信 | 证据画面像真的吗？有没有编出来的结果被包装成真实运行？ |
| 对照 | 和参考片并排，本片哪一行明显更空、更小、更慢？ |

入场动画进行到一半的画面（半透明、还没到位）不算问题。

**回报格式（控制在 30 行以内，只写文字，不要贴图）：**

```
最影响观看的三个问题（按严重程度）：
1. [时间点] 现象 —— 为什么观众会受影响 —— 建议怎么改
2. …
3. …

其余问题：
- [P0 观众一定会注意到、而且妨碍理解：字错了、看不清、声画对不上、标注指错地方、元素互相遮挡]
- [P1 明显走样：版式连着重复、标注偏了、音效听不见、网页是静止截图、主体小]
- [P2 质感上的小毛病：留白、密度、样式]
每条：[级别] [时间点] 现象

做得好的一处：[时间点] 是什么（留着别改）
没看到、没法判断的：……
```
