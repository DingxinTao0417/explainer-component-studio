# 当前用户的个人制作预设

这些是本人的既有项目偏好和本机位置，非所有科普题材的硬规则；新请求和实际文件优先。文件不在时，说明该参考不可用，使用明确记录的画风描述或新的风格样图，不搜遍用户磁盘。

## 输出和画风

- 编导职责现包含开头钩子、正文和结尾；每段自主选择 AI 画面、外部视频/图片、本人录屏或可控图解，并实际查找素材与编写可照做的录屏清单。
- 工作区：`当前项目工作区`。新片用 `projects/<日期>_<主题简称>/` 独立目录，不覆盖现有 `shots/01`、`shots/02`。
- 语言：简体中文口语讲解；横屏精确 16:9，交付 1920×1080、24 fps。
- 当前美术方向：白色背景、Codex 蓝 `#2563eb` 强调、薄荷绿 `#81c9b0` 辅助、深色正文与轻阴影；结构清楚、留白充足。暖金与橙黄不再作为默认强调。面向成年人，不默认儿童卡通或真人讲述。
- 上述美术方向用于 AI 插画与后期图形；真实录屏、资料图和纪实视频保留原貌，通过画幅、标注与剪辑衔接统一，不把它们重绘成插画。用户可按主题选择出镜，不把旧动画的无人物画面变成禁止真人的限制。
- 可查看的画风来源：`./shots/01/scene01_reference.png`；第二幅参考：`./shots/02/scene02_reference.png`。二者提供本人的既有美术风格，不规定新主题也出现教程文件夹、浏览器、山水海报或点赞图标。
- 留底部约 13% 字幕区，重要内容不贴边。第一幅原图是 1672×941，不能把它的实际文件尺寸写成 1920×1080。
- 第一段完整生成版曾获用户满意。第二段 Budget 候选已生成，未收到用户对画质的明确验收；不得把其质量也标为用户已认可。

## 视频基线

已保存的可用工作流：`./shots/02/h3_scene02_budget_v1.json`；原提交快照：`h3_scene02_submitted_budget_v1.json`（同目录）。复制为新镜头后替换旧提示词、参考图、配音、时长、输出前缀和状态，保留节点与连线。不要把第二段的内容当成新片默认材料。

Budget 参数（2026-09-17 实测运行过）：

| 项目 | 值 |
|---|---|
| 生成画布 | 0.50 MP / 32 网格，960×544 |
| 参考尺寸 | match |
| 采样 | 完整 20 步，Lightning 关闭，res_multistep / simple |
| 后处理 | RTXVideoSuperResolution 2× HIGH → 1920×1088 |
| 成片 | 上下各裁 4 px，1920×1080，24 fps |
| 音轨 | LoadAudio → CreateVideo.audio，使用对应镜头的用户原配音；模型生成音轨不进入最终输出 |

帧数与实际时长按当前 H3 技能/工作流公式。6.14 秒输入曾得到 158 帧、约 6.583 秒画面及完整旁白；节点运行共 118.71 秒。这个单次结果与旧版不是同一镜头，不构成对照实验；不承诺每段耗时、扣费比例或超分可恢复丢失细节。

仅在执行工作流时读取节点 ID 与本机操作细节；这些实现参数不进入口播稿或画面上的用户内容。

## 配音现状

用户明确要保留自己的声音。当前有第一、二段旧稿的配音文件，这不等于拥有新稿的音频或可调用的 TTS 音色 ID。新稿默认标为待配音，先完成其他前期产物；有已授权可用的新配音生成方式时继续处理。不要悄悄换声、拼旧句子或加速声音来凑视频时长。
