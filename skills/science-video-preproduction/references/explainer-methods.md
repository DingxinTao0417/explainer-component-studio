# 讲解视频症状方法卡

分镜遇到具体难点、制作返修或叙事审查时按症状读取。先描述实际问题，再选有关卡片；可不用，不设最低数量。以下 `EX-` 是本技能的适配编号，不是原参考包的方法编号或效果保证。

| 症状 | 优先查看 |
| --- | --- |
| 开头有标题却没有观看理由 | EX-01 |
| 结论突然出现，过程看不懂 | EX-02 |
| UI 太小或放大后不知身在何处 | EX-03 |
| 旁白、正文卡和画面重复同一句话 | EX-04 |
| 两个例子讲完，观众仍找不到共性 | EX-05 |
| 换场突兀，转场只是遮一下原画面 | EX-06 |
| 音效堆满，重点反而不清楚 | EX-07 |
| 缺素材就卡住，或靠无关 B-roll 填时长 | EX-08 |

## EX-01｜首屏给对象与疑问，正文兑现

- **适用**：讲解开头空泛、与正文脱节。
- **动作**：选一个实际可见的结果、问题或差异，安排第一幅画面、对应声音、进入正文的连接和兑现镜头；有已有配音时围绕声音设计。
- **替代**：没有真实演示结果时，用已知输入提出问题，或使用标明假设的案例动画。
- **误用边界**：不伪造错误结果或收益；不擅自新增口播，不套固定三秒或固定十秒开场。
- **验收**：开头对象可识别，正文确实回答同一问题，回答依据在画面中可找到。

## EX-02｜把触发、变化与结果连起来

- **适用**：表格筛选、流程连线、状态更新或因果动画跳过关键一步。
- **动作**：先给初态，再显示输入或条件变化，随后执行变化，最后展示终态并留出核对时间。连线表达推导时，线到达目标后才出现所推导的结果。
- **替代**：复杂变形可改成保持对象位置的前后状态切换，明确标出变化处。
- **误用边界**：不把所有对象都强制串行出现；状态对照不是软件实际计算性能的证据。
- **验收**：正常速度下能说明什么触发了变化，终态与条件一致，无旧状态重影。

## EX-03｜全貌定位，局部核对，回看结果

- **适用**：软件界面或数据密集，等比缩放后文字过小。
- **动作**：先交代全貌，再聚焦关键控件、条件或行；保持标题、行号、选中态等身份线索，必要时回到全貌。
- **替代**：真实 UI 无法放大时，把重点区域作为放大窗并标明原位置；示意图可减少无关字段。
- **误用边界**：不拉伸软件截图、不篡改实录数据、不为了景别变化不停推拉。
- **验收**：成片画幅下关键内容可读，观众能判断局部来自哪里、结果影响了哪里。

## EX-04｜画面与口播分别承担信息

- **适用**：卡片只是重贴旁白，画面没有证据或变化。
- **动作**：把可见的步骤、关系和差异交给画面；口播解释原因、条件与意义，强调标题提炼重点。保留阅读所需的准确数字和标签。
- **替代**：无可用素材时采用可控示意图，不用无关办公镜头填空。
- **误用边界**：逐字字幕为可访问性服务，可与声音重复；定义、专名和必要复述不因“去重复”被删。
- **验收**：画面在字幕之外确实增加证据、解释或定位作用；不形成多块长文争抢阅读。

## EX-05｜相同维度对齐后再抽象

- **适用**：多案例比较、归纳共同方法、说明差异。
- **动作**：提取每例的同一比较维度，用一致位置与视觉编码对齐；标出对应关系，再呈现共同结论和适用边界。
- **替代**：画幅容不下并排时，沿用同一布局顺序展示并回收比较，不把文字缩小硬塞。
- **误用边界**：例子没有共同机制时不强行归纳；不能为了凑结构改事实或制造对称。
- **验收**：观众能指出结论来自哪几处对应关系，案例差异也没有被掩盖。

## EX-06｜先决定交接信息，再选转场

- **适用**：场景之间缺少关联，或重复使用遮挡却没有内容交接。
- **动作**：按 [镜头组设计](shot-groups.md) 明确切法和切点；继承必要的对象、方向或声音线索。转场结束确实进入下一状态或下一对象。
- **替代**：没有合理匹配就采用硬切、短停留或简短定位提示。
- **误用边界**：不把转场本身当段落的新信息；不拖长转场侵占关键阅读时间。
- **验收**：检查 A 画面、转场中态、B 画面及其阅读停留；画布覆盖完整，焦点交接清楚。

## EX-07｜每段声音有主次与落点

- **适用**：全片一样满、每次出现都加音效、音乐遮盖讲解。
- **动作**：先确定本段声音主角，再处理其余声部；动作音对准实际变化，必要时用减弱、停顿或安静突出关键结论。按段落调整音乐进入、延续与退出。
- **替代**：保留清楚旁白与少量关键动作音即可；不为抽象图解强行补环境声。
- **误用边界**：不能用量测、波形或字幕替代试听；不凭想象诊断声音，也不把人声切碎以适配卡点。
- **验收**：实际试听可懂度、同步、段落交接与密度；无法试听则记录未验证。

## EX-08｜先用现有材料实现理解任务

- **适用**：材料不足、B-roll 无关、生成复杂而讲解增益小。
- **动作**：先写缺失的具体信息，再判断已有素材能否裁切、重排、标注或图解；必要缺口才转成明确补录/生成任务。
- **替代**：不影响真实证据要求时，采用明确标示的示意动画；缺关键事实证据则保留待补状态。
- **误用边界**：不能拿模拟替代用户要求的真实能力证明，也不能因素材现成就改变核心观点。
- **验收**：每项素材承担明确职责，采用内容足以支持讲解目标；未取得的证据不被包装成完成。

## 使用与积累

采用时记录“症状 → 本期证据/计划 → 选用方法 → 具体动作 → 验收点”；编号仅供索引，不替代制作说明。新卡来自可复核的项目观察，写明适用条件、反例或限制；不要把一次审美偏好升级为全片强制规则。

方法参考《秋拾 AI 脚本编导》V3.5 的镜头组接/方法库、《秋拾·AI短片诊断》V2.7 的按症状检索与声音诊断框架，并结合本库既有的界面、连线和表格问题改写。未复制其案例库、台词或完整镜头排列，未验证其引用案例的全部原始证据；不把这些适配卡称为秋拾原卡。
