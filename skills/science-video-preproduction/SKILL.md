# 科普视频前期：稿子与分镜

这个 skill 的目标是让稿子一听就想接着听，让分镜一看就知道画面该怎么拍、怎么做。做出来的东西直接交给 science-video-director 制作，所以画面要按它的标准来设计。它的标准见 `../science-video-director/guide/visual-grammar.md`：
- 开头先亮结果；
- 画面里有人；
- 主持人、证据、结构卡、比喻 / 情境四类画面轮流出现；
- 字大，节奏快。

## 从最少的输入开始

- 有主题就可以动手。受众和时长没说时，先按“普通职场人、横屏 3 分钟左右”写初稿，在交付时说明。只有当主题的含义或用户立场会改变结论时，才先问一句。
- 用户给了原稿，先分清他要的是“整理润色”还是“改写扩展”。核心观点和语气保持不变。
- 开工前读 `../science-video-director/guide/style-profile.md`，了解频道方向和偏好。
- 主持人形式和视觉调性会影响分镜。用户在场、要出分镜时，用选项框一次问清；用户不在，或只要稿子时，按推荐先假设，在 BRIEF 里写明“假设，做片时确认”，不要因此停工。

## 一、写稿

读 `guide/writing.md`。要点如下：

1. **先写一句话**：观众看完能明白或能做到什么。再把因果链或讲解顺序排出来，每段只承担一个作用。
2. **先发散再写**：核心洞察和钩子各写 5 个候选，其中至少 2 个是普通模型不太会想到的，再挑（做法见 `../science-video-director/guide/ideation.md`）。交给用户 2–3 个不同角度的开头，每个都写清“第一句话 + 第一个画面”。推荐一个，并用它写完整稿。钩子要在前 8 秒成立。优先用能拍出来的结果、反差或问题，不编造数据和个人经历。
3. **正文**：每一段都推进一次理解，用演示、证据、例子或推理来推进，不靠反复吊胃口。每一章开头有一句话告诉观众现在讲到哪。
4. **结尾**：回答开头的问题，给一个具体可做的动作。
5. **口播稿**：简体中文口语，短句，术语要解释。纯文本，只放要读出来的字，不混入镜头号、注释和来源。
6. **核实**：外部事实、数字和软件能力，都要去官方或原始资料核对，并记下出处。查不到依据的，就收窄说法或删掉。事实、观点和比喻分开写。写稿前先列一张“不能说错的事”清单（数字、版本、能力边界），成稿后逐条对一遍。

## 二、出分镜

读 `guide/shot-planning.md`。分镜写成表格，一行一个镜头：

| 镜号 | 章 | 旁白（原句） | 类型 | 画面 | 画面文字 | 素材来源 |
| --- | --- | --- | --- | --- | --- | --- |

- **按意思分镜**：一个镜头装一个意思单位，通常两三句旁白；转折句和设问归下一镜。先列一张版式节奏表（人在哪 / 素材装在哪），确认没有连着 3 镜一个样，再写逐镜。
- **类型**：主持人 / 证据 / 结构 / 比喻（含 Pexels 这类情境实拍），四类轮流出现。旁白里出现新名词、数字、对比或步骤的地方，要安排对应的画面变化。
- **手法和组件**：画面一栏写上用到的手法卡号（手法库 `INDEX.md`），以及品牌组件名（brand-kit README）。全片要有一个视觉母题和一个惊喜时刻。
- **时长**：没有配音时写估算时长，并标明“估算”。拿到配音后，时间以实际声音为准。
- **素材来源**：录屏、Pexels 实拍、用户视频、AI 视频（由用户生成）、生图插画、组件或手写图形。能用真实素材表达的优先用真实素材。

## 三、任务清单

把需要人去做、或需要准备的素材，全部写进 `planning/TASKS.md`，按下面四节分开。格式参照 `../science-video-director/guide/assets.md`：

- **录屏任务卡**：起始画面、逐步操作、可以直接复制的输入、预期结果、停留时间、文件名。步骤要按当前真实界面核对过，没核对的标“待核实”。
- **真人口播任务卡**：本期决定用真人出镜时才需要。写明台词、拍摄要求和文件名。
- **外部素材**：给出查到的具体候选，包括页面链接、作者和用途，不能只给检索关键词。要当证据用的网页，写清网址和要指给观众看的那句原文，做片时用 `pageshot.mjs` 采。
- **AI 画面**：只写确实要用 AI 生图或 AI 视频的镜头（静图加推近能讲清的，就不需要 AI 视频）。生图镜头写生图提示词；需要 AI 视频的，再写逐对象、逐时段的视频提示词和回传清单。

## 交付与落盘

只做用户要的部分。只要稿子就只交稿子，要分镜才出分镜。

需要落盘时，用 `episode.py init` 建项目，文件写进 `planning/`，以后 science-video-director 可以直接接着做。口播稿写好后用 `add` 登记：

```powershell
$ep = '<skills目录>/science-video-director/scripts/episode.py'
python -X utf8 $ep init --slug <简称> --title <标题>
python -X utf8 $ep add <项目> <项目>/input/script/口播稿.txt --role script
```

| 文件 | 内容 |
| --- | --- |
| `input/script/口播稿.txt` | 最终口播，纯文本 |
| `planning/BRIEF.md` | 导演阐述初稿，用 `../science-video-director/templates/brief-template.md` |
| `planning/STORYBOARD.md` | 分镜表、钩子备选、事实出处、读音提示（易读错的专名和数字） |
| `planning/TASKS.md` | 录屏、口播任务卡，外部素材候选，AI 画面提示词（有需要时才写） |

交付时用两三句话说明：推荐了哪个钩子、为什么推荐，哪些事实已核实，哪些还需要用户补充。
